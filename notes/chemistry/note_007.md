## 1. 本节前置：国内高中化学基础唤醒

本切片覆盖无机非金属元素最核心的**四大主族（18 族稀有气体、17 族卤素、16 族氧族、15 族氮族）**。EJU 无机化学不考偏怪冷门，专考**四大高频板块**：① 气体的实验室制法、除杂、干燥与收集；② 三大工业制法（接触法制硫酸、哈伯法制氨、奥斯特瓦尔德法制硝酸）及其守恒计算；③ 氧化物与含氧酸的酸性/氧化性规律；④ 同素异形体与试剂保存法。

### 1.1 国内高中核心基础快速唤醒

1. **18 族稀有气体（希ガス）**
   - $\text{He}, \text{Ne}, \text{Ar}, \text{Kr}, \text{Xe}$ 均为无色无臭的**单原子分子**，化学性质极其稳定。
   - **空气体积分数**（必背）：$\text{N}_2\ (78\%)$、$\text{O}_2\ (21\%)$、$\text{Ar}\ (0.9\%)$、$\text{CO}_2\ (0.04\%)$。
   - $\text{He}$ 沸点全物质最低（$-269^\circ\text{C}$），最接近理想气体，密度仅次于 $\text{H}_2$。
2. **17 族卤素（ハロゲン：$\text{F}, \text{Cl}, \text{Br}, \text{I}$）**
   - 最外层 7 个电子，易得 1 个电子形成 $-1$ 价阴离子。
   - **单质常温状态与颜色**：$\text{F}_2$ 淡黄气、$\text{Cl}_2$ 黄绿气、$\text{Br}_2$ 红褐液、$\text{I}_2$ 紫黑固。
   - **氧化性（反应活性）递减**：$\text{F}_2 \gt \text{Cl}_2 \gt \text{Br}_2 \gt \text{I}_2$（前能置后，如 $\text{Cl}_2 + 2\text{I}^- \rightarrow 2\text{Cl}^- + \text{I}_2$；但 $\text{F}_2$ 通入水溶液会直接与水剧烈反应放 $\text{O}_2$）。
   - **卤化氢（$\text{HX}$）**：唯有 $\text{HF}$ 因存在**分子间氢键**导致沸点异常高（$20^\circ\text{C}$），且在水溶液中难以电离，是**唯一的弱酸**，并能腐蚀玻璃（$\text{SiO}_2$）。
3. **16 族氧（$\text{O}$）与硫（$\text{S}$）**
   - **地壳元素含量（克拉克数，クラーク数）前六名**：**氧硅铝铁钙钠**（$\text{O} \gt \text{Si} \gt \text{Al} \gt \text{Fe} \gt \text{Ca} \gt \text{Na}$）。
   - **氧化物分类**：金属氧化物多为**碱性氧化物**（如 $\text{Na}_2\text{O}, \text{CaO}$）；非金属氧化物多为**酸性氧化物**（如 $\text{CO}_2, \text{SO}_3$）；$\text{Al}_2\text{O}_3, \text{ZnO}, \text{PbO}$ 为**两性氧化物**。
   - **硫的同素异形体**：斜方硫（$\text{S}_8$ 环状）、单斜硫（$\text{S}_8$ 环状）均溶于 $\text{CS}_2$；弹性硫/橡胶状硫（$\text{S}_x$ 链状）不溶于 $\text{CS}_2$。
   - **浓硫酸五大特性**：不挥发性（制 $\text{HCl}, \text{HNO}_3$）、强氧化性（热浓硫酸氧化 $\text{Cu}$）、脱水性（乙醇脱水成乙烯）、吸水性（作酸性干燥剂）、稀释剧烈放热（**酸入水**）。
4. **15 族氮（$\text{N}$）与磷（$\text{P}$）**
   - **氨气（$\text{NH}_3$）**：极易溶于水，水溶液呈弱碱性；遇 $\text{HCl}$ 产生白烟（$\text{NH}_4\text{Cl}$ 固体小颗粒）；实验室用 $\text{NH}_4\text{Cl}$ 与 $\text{Ca(OH)}_2$ 共热制取。
   - **硝酸（$\text{HNO}_3$）**：强酸 + 强氧化性，常温即可溶解不活泼金属 $\text{Cu}, \text{Ag}, \text{Hg}$（稀硝酸放 $\text{NO}$，浓硝酸放 $\text{NO}_2$）；浓硝酸使 $\text{Al}, \text{Fe}, \text{Ni}$ 发生**钝化（不動態）**；见光受热易分解，需用**棕色瓶（褐色びん）**冷暗处保存。
   - **三大工业合成法**：
     - **接触法（硫酸）**：$\text{S} \rightarrow \text{SO}_2 \xrightarrow{\text{V}_2\text{O}_5} \text{SO}_3 \xrightarrow{\text{浓}\text{H}_2\text{SO}_4} \text{発煙硫酸} \rightarrow \text{H}_2\text{SO}_4$
     - **哈伯法（合成氨）**：$\text{N}_2 + 3\text{H}_2 \xrightleftharpoons{\text{Fe}_3\text{O}_4} 2\text{NH}_3$
     - **奥斯特瓦尔德法（硝酸）**：$\text{NH}_3 \xrightarrow{\text{Pt}} \text{NO} \rightarrow \text{NO}_2 \rightarrow \text{HNO}_3$

### 1.2 中日化学体系差异提醒（EJU 避坑必看）

1. **气体收集方法的名称完全相反（最高频踩坑！）**：
   - 中国说“**向上排空气法**”（密度比空气大，气体沉在瓶底），日本叫 **「下方置換（かほうちかん）」**（以**气体去向**命名：气体往下方沉）。
   - 中国说“**向下排空气法**”（密度比空气小，气体浮在瓶顶），日本叫 **「上方置換（じょうほうちかん）」**（气体往上方浮）。
   - 记忆铁律：**日文看气体去哪儿，中文看空气往哪儿排**！所以 $\text{Cl}_2$ 是**下方置換**，$\text{NH}_3$ 是**上方置換**。
2. **「黄リン」就是国内的“白磷”**：
   - 日本教材统一将 $\text{P}_4$ 称为 **黄リン（おうりん）**，淡黄色蜡状固体，剧毒、易自燃，**水中保存**；红磷称为 **赤リン（せきりん）**，无毒、网状高分子（$\text{P}_x$）。
3. **「さらし粉」的化学式写法差异**：
   - 国内常写漂白粉有效成分为 $\text{Ca(ClO)}_2$（与 $\text{CaCl}_2$ 混合），日本 EJU 教材统一把さらし粉写作复盐结晶水合物形式：**$\text{CaCl(ClO)}\cdot\text{H}_2\text{O}$**。
4. **$\text{SiO}_2$ 与 $\text{HF}$ 反应的产物写法差异**：
   - 国内高中写 $\text{SiO}_2 + 4\text{HF} \rightarrow \text{SiF}_4\uparrow + 2\text{H}_2\text{O}$；日本 EJU 教材多写生成**六氟硅酸（ヘキサフルオロケイ酸）**：$\text{SiO}_2 + 6\text{HF} \rightarrow \text{H}_2\text{SiF}_6 + 2\text{H}_2\text{O}$。两种都要认识，EJU 优先记后者！
5. **五氧化二磷写作 $\text{P}_4\text{O}_{10}$（十酸化四リン）**：
   - 国内习惯写简式 $\text{P}_2\text{O}_5$，日本 EJU 严格按真实分子式写作 **$\text{P}_4\text{O}_{10}$**。
6. **$\text{H}_3\text{PO}_4$ 归为「中程度の酸（中强酸）」**：
   - 日本教材将第 3 周期最高价含氧酸明确分级：$\text{H}_2\text{SiO}_3$（弱酸）$\lt \text{H}_3\text{PO}_4$（中程度の酸）$\lt \text{H}_2\text{SO}_4$（強酸）$\lt \text{HClO}_4$（強酸）。

> ⚠️ **原教材印刷勘误提醒（讲师逐页人工核对参考图 `page_0091.jpg`–`page_0105.jpg` 发现）**：
> 1. **原书 P.90（PDF 第 91 页）**：`④ He（ヘリウム）前期対中、もっとも理想気体に近く` 属于**印刷错字**！正确应为 **`全気体中（ぜんきたいちゅう）`**（所有气体中）。
> 2. **原书 P.92（PDF 第 93 页）**：`塩素 Cl₂ 実験的製法 ① 酸化マンガン(IV)に濃硫酸を加えて加熱する` 属于**严重印刷错误**！正确应为 **`濃塩酸（のうえんさん）`**（原书下方方程式本身写的是 $\text{MnO}_2 + 4\text{HCl}$）。
> 3. **原书 P.96（PDF 第 97 页）**：`Cao + H₂O → Ca(OH)₂` 大小写笔误，正确为 **`CaO`**；此外 `塩基性酸化物 + 酸 → 塩 + 水` 的示例给了 `ZnO + 2HCl → ZnCl₂ + H₂O`，注意 $\text{ZnO}$ 严格属于**両性酸化物**（虽可与酸中和，碱性氧化物标准示例宜记 $\text{CaO}$ 或 $\text{CuO}$）。
> 4. **原书 P.101（PDF 第 102 页）**：
>    - **哈伯法方程式漏配平**：原书印成 `N₂ + H₂ --(Fe₃O₄)--> 2NH₃`，漏掉了 $\text{H}_2$ 前面的系数 **`3`**（且实际为高温高压可逆平衡），正确应为 **`N₂ + 3H₂ ⇄ 2NH₃`**！
>    - 原书将 $\text{NH}_4\text{NO}_2$ 写作「亜硝酸アンモニア」、$\text{NH}_4\text{Cl}$ 写作「塩化アンモニア」，日本正规化学命名应为 **`亜硝酸アンモニウム`** 与 **`塩化アンモニウム`**（铵盐用 `アンモニウム`，氨分子才用 `アンモニア`）。

## 2. 日文化学核心词汇、物质名称与假名注音（板书必备）

### 2.1 希ガス（18 族）与ハロゲン（17 族）
- **希ガス（きがす / kigasu）** — 稀有气体（18 族）
- **単原子分子（たんげんしぶんし / tangenshi bunshi）** — 单原子分子
- **ヘリウム（へりうむ / heriumu）** — 氦（$\text{He}$）
- **ネオン（ねおん / neon）** — 氖（$\text{Ne}$）
- **アルゴン（あるごん / arugon）** — 氩（$\text{Ar}$）
- **液体空気の分留（えきたいくうきのぶんりゅう / ekitai kūki no bunryū）** — 液态空气的分馏
- **超低温冷媒（ちょうていおんれいばい / chōteion reibai）** — 超低温制冷剂
- **封入ガス（ふうにゅうがす / fūnyū gasu）** — 填充气体（灯泡/荧光灯）

- **フッ素（ふっそ / fusso）** — 氟（$\text{F}_2$，淡黄色气体）
- **塩素（えんそ / enso）** — 氯（$\text{Cl}_2$，黄绿色气体）
- **臭素（しゅうそ / shūso）** — 溴（$\text{Br}_2$，红褐色液体）

- **ヨウ素デンプン反応（ようそでんぷんはんのう / yōso denpun hannō）** — 碘-淀粉反应（青紫色）
- **ヨウ化カリウムデンプン紙（ようかかりうむでんぷんし / yōka kariumu denpunshi）** — 碘化钾淀粉试纸

- **蛍石（ほたるいし / hotaruishi）** — 萤石（$\text{CaF}_2$，フッ化カルシウム）
- **ポリエチレン容器（ぽりえちれんようき / poriechiren yōki）** — 聚乙烯容器（保存 $\text{HF}$）
- **塩化水素（えんかすいそ / enka suiso）** — 氯化氢（$\text{HCl}$；水溶液叫 **塩酸**）

- **亜塩素酸・塩素酸・過塩素酸（あえんそさん・えんそさん・かえんそさん）** — 亚氯酸（$\text{HClO}_2$）・氯酸（$\text{HClO}_3$）・高氯酸（$\text{HClO}_4$）

- **リン鉱石・ケイ砂・コークス（りんこうせき・けいしゃ・こーくす）** — 磷矿石（$\text{Ca}_3(\text{PO}_4)_2$）・硅砂（$\text{SiO}_2$）・焦炭（$\text{C}$）
- **ハロゲン化銀（はろげんかぎん / harogenka gin）** — 卤化银（感光性，棕色瓶保存）

### 2.4 关键化学方程式与公式的日语课堂口语读法
1. **氯气实验室制法**：$\text{MnO}_2 + 4\text{HCl} \xrightarrow{\text{加熱}} \text{MnCl}_2 + 2\text{H}_2\text{O} + \text{Cl}_2\uparrow$
   - 读法：`さんかマンガンよん たす よん エイチシーエル かねつ やじるし えんかマンガンに たす に エイチツーオー たす シーエルツー はっせい`
2. **哈伯法合成氨**：$\text{N}_2 + 3\text{H}_2 \xrightleftharpoons{\text{Fe}_3\text{O}_4} 2\text{NH}_3$
   - 读法：`ちっそ たす さん すいそ しさんかさんてつ しょくばい かぎゃくやじるし に アンモニア`
3. **奥斯特瓦尔德法合体式**：$\text{NH}_3 + 2\text{O}_2 \rightarrow \text{HNO}_3 + \text{H}_2\text{O}$
   - 读法：`アンモニア たす に さんそ やじるし しょうさん たす みず`
4. **二氧化硫与硫化氢归中反应**：$\text{SO}_2 + 2\text{H}_2\text{S} \rightarrow 3\text{S} + 2\text{H}_2\text{O}$
   - 读法：`にさんかいおう たす に りゅうかすいそ やじるし さん いおう たす に みず`

#### ① 希ガス（18 族）必考要点
- **电子结构**：最外层电子 8 个（仅 $\text{He}$ 为 2 个），**価電子 $= 0$ 个**，极其稳定，单原子分子，沸点极低。

### 3.2 酸素・酸化物・オキソ酸（16 族，原书 P.95–P.97）

#### ① 酸素（$\text{O}_2$）与オゾン（$\text{O}_3$）
- **$\text{O}_2$ 实验室制法**：
  1. $2\text{H}_2\text{O}_2 \xrightarrow{\text{MnO}_2} 2\text{H}_2\text{O} + \text{O}_2\uparrow$（常温催化分解）
  2. $2\text{KClO}_3 \xrightarrow[\text{加熱}]{\text{MnO}_2} 2\text{KCl} + 3\text{O}_2\uparrow$
  3. $2\text{H}_2\text{O} \xrightarrow{\text{電気分解}} 2\text{H}_2\uparrow + \text{O}_2\uparrow$
- **$\text{O}_3$ 制法与检验**：$3\text{O}_2 \rightleftarrows 2\text{O}_3$（紫外线或无声放电）；淡青色、特異臭、**折れ線型分子**；强氧化性，使湿润的 $\text{KI}$-淀粉试纸变蓝：
  $$2\text{KI} + \text{O}_3 + \text{H}_2\text{O} \rightarrow \text{O}_2 + \text{I}_2 + 2\text{KOH}$$

### 3.3 硫黄（16 族）及其化合物与例题 1（接触法计算，原书 P.98–P.100）

#### ① $\text{H}_2\text{S}$ 与 $\text{SO}_2$ 核心对比与反应
- **制法**：
  - $\text{H}_2\text{S}$：$\text{FeS} + \text{H}_2\text{SO}_4 \rightarrow \text{FeSO}_4 + \text{H}_2\text{S}\uparrow$（弱酸の遊離）
  - $\text{SO}_2$ 实验室 ①：$\text{NaHSO}_3 + \text{H}_2\text{SO}_4 \rightarrow \text{NaHSO}_4 + \text{H}_2\text{O} + \text{SO}_2\uparrow$（弱酸の遊離）
  - $\text{SO}_2$ 实验室 ②：$\text{Cu} + 2\text{H}_2\text{SO}_4\text{（濃）} \xrightarrow{\text{加熱}} \text{CuSO}_4 + 2\text{H}_2\text{O} + \text{SO}_2\uparrow$（酸化還元反応）
  - $\text{SO}_2$ 工业：$\text{S} + \text{O}_2 \rightarrow \text{SO}_2$ 或 $4\text{FeS}_2 + 11\text{O}_2 \rightarrow 2\text{Fe}_2\text{O}_3 + 8\text{SO}_2$
- **共通点**：溶于水呈弱酸性、有还原性、有毒气体。
- **相异点**：$\text{H}_2\text{S}$ 为**腐卵臭**（使金属离子硫化物沉淀）；$\text{SO}_2$ 为**刺激臭**（利用还原性漂白丝绸・羊毛）。
- **两者归中反应**（$\text{SO}_2$ 作氧化剂，$\text{H}_2\text{S}$ 作还原剂）：
  $$\text{SO}_2 + 2\text{H}_2\text{S} \rightarrow 3\text{S}\downarrow + 2\text{H}_2\text{O}$$
- **濃硫酸（90%以上）五大性质**：① 不揮発性（制 $\text{HCl}$）；② 热氧化性（溶 $\text{Cu}$）；③ 脱水性（$\text{C}_2\text{H}_5\text{OH} \xrightarrow{\text{濃}\text{H}_2\text{SO}_4} \text{C}_2\text{H}_4 + \text{H}_2\text{O}$）；④ 吸湿性；⑤ 溶解热大（稀释时必须**向水中缓缓加入浓硫酸**）。

##### 【分步标准解答】

**第 1 步：写出接触法三步反应方程式，确立硫原子守恒关系**
1. $\text{S} + \text{O}_2 \rightarrow \text{SO}_2$
2. $2\text{SO}_2 + \text{O}_2 \xrightleftharpoons{\text{V}_2\text{O}_5} 2\text{SO}_3$
3. $\text{SO}_3 + \text{H}_2\text{O} \rightarrow \text{H}_2\text{SO}_4$（工业上先用浓硫酸吸收为发烟硫酸，再稀释）

由硫原子守恒可知：**$1\text{ mol}$ 的 $\text{S}$ 完全反应生成 $1\text{ mol}$ 的 $\text{H}_2\text{SO}_4$**。

**第 2 步：计算硫黄的物质的量（$\text{mol}$）**
- 已知 $\text{S}$ 的质量为 $3.2\text{ kg} = 3200\text{ g}$，原子量 $\text{S} = 32\text{ g/mol}$：
$$n(\text{S}) = \frac{3200\text{ [g]}}{32\text{ [g/mol]}} = 100\text{ [mol]}$$

**第 3 步：计算生成的纯 $\text{H}_2\text{SO}_4$ 质量**
- 由 $1:1$ 守恒，生成 $\text{H}_2\text{SO}_4$ 为 $100\text{ mol}$。$\text{H}_2\text{SO}_4$ 的摩尔质量为 $1 \times 2 + 32 + 16 \times 4 = 98\text{ g/mol}$：
$$m(\text{H}_2\text{SO}_4) = 98\text{ [g/mol]} \times 100\text{ [mol]} = 9800\text{ [g]}$$

**第 4 步：换算为质量分数 $98\%$ 的硫酸溶液质量**
- 溶质质量分数 $98\%$ 意味着“每 $100\text{ g}$ 溶液中含纯 $\text{H}_2\text{SO}_4\ 98\text{ g}$”，因此溶液总质量为：
$$m_{\text{溶液}} = 9800 \times \frac{100}{98} = 10000\text{ [g]} = 10\text{ [kg]}$$

> 💡 **讲师批注**：**防错提醒！** 很多同学会把最后一步误乘成 $9800 \times 0.98$！记住：**溶液质量永远大于溶质质量**，从纯溶质算溶液，一定要**除以浓度**（$\div 0.98$ 即 $\times \dfrac{100}{98}$）。本题给出 $3.2\text{ kg}$ 与 $98\%$，均为 2 位有效数字，故结果为 $10\text{ kg}$。

##### 【最终答案】
**$10\text{ kg}$**

### 3.4 窒素（15 族）及其化合物与例题 2（奥斯特瓦尔德法，原书 P.101–P.103）

#### ① 窒素（$\text{N}_2$）与アンモニア（$\text{NH}_3$）
- **$\text{N}_2$ 制法**：工业用**液体空気の分留**；实验室加热亚硝酸铵水溶液：$\text{NH}_4\text{NO}_2 \xrightarrow{\text{加熱}} \text{N}_2\uparrow + 2\text{H}_2\text{O}$。
- **$\text{NH}_3$ 工业制法（ハーバー・ボッシュ法，哈伯法）**：
  $$\text{N}_2 + 3\text{H}_2 \xrightleftharpoons[\text{高温・高圧}]{\text{Fe}_3\text{O}_4} 2\text{NH}_3$$
- **$\text{NH}_3$ 实验室制法**：氯化铵与氢氧化钙固体共热（原书未列方程式，务必补记！）：
  $$2\text{NH}_4\text{Cl} + \text{Ca(OH)}_2 \xrightarrow{\text{加熱}} \text{CaCl}_2 + 2\text{H}_2\text{O} + 2\text{NH}_3\uparrow$$

#### ③ 氮氧化物（$\text{NO}, \text{NO}_2$）与硝酸（$\text{HNO}_3$）
- **$\text{NO}$（无色、不溶于水）**：$3\text{Cu} + 8\text{HNO}_3\text{（希）} \rightarrow 3\text{Cu(NO}_3)_2 + 4\text{H}_2\text{O} + 2\text{NO}\uparrow$；遇空气立即变红棕色：$2\text{NO} + \text{O}_2 \rightarrow 2\text{NO}_2$。
- **$\text{NO}_2$（红褐色、有毒）**：$\text{Cu} + 4\text{HNO}_3\text{（濃）} \rightarrow \text{Cu(NO}_3)_2 + 2\text{H}_2\text{O} + 2\text{NO}_2\uparrow$；溶于水：$3\text{NO}_2 + \text{H}_2\text{O} \rightarrow 2\text{HNO}_3 + \text{NO}$；常温下与无色 $\text{N}_2\text{O}_4$ 存在平衡：$2\text{NO}_2 \rightleftarrows \text{N}_2\text{O}_4$。
- **$\text{HNO}_3$ 实验室制法**：$\text{NaNO}_3 + \text{H}_2\text{SO}_4\text{（濃）} \xrightarrow{\text{加熱}} \text{NaHSO}_4 + \text{HNO}_3\uparrow$（揮発性酸の遊離）。
- **$\text{HNO}_3$ 性质**：① 强酸 + 强氧化性（常温溶 $\text{Cu}, \text{Ag}, \text{Hg}$）；② 浓硝酸使 **$\text{Al}, \text{Fe}, \text{Ni}$** 形成致密氧化膜发生**不動態（钝化）**；③ 见光受热分解，装**褐色びん**冷暗处保存。

##### 【分步标准解答】

**第 1 步：推导奥斯特瓦尔德法的总反应式（合体式）**
1. $4\text{NH}_3 + 5\text{O}_2 \xrightarrow{\text{Pt}} 4\text{NO} + 6\text{H}_2\text{O}$ …… ①
2. $2\text{NO} + \text{O}_2 \rightarrow 2\text{NO}_2$ …… ②
3. $3\text{NO}_2 + \text{H}_2\text{O} \rightarrow 2\text{HNO}_3 + \text{NO}$ …… ③

将 $① + ② \times 3 + ③ \times 2$ 消去中间产物 $\text{NO}$ 与 $\text{NO}_2$，再两边同除以 $4$，得合体式：
$$\text{NH}_3 + 2\text{O}_2 \rightarrow \text{HNO}_3 + \text{H}_2\text{O}$$
> 💡 **讲师批注**：由合体式（或直接看 **N 原子守恒**）立刻得出：$1\text{ mol NH}_3$ 完全转化可生成 **$1\text{ mol HNO}_3$**！EJU 也常问“合体式中 $\text{O}_2$ 的系数是多少？”，记住：**1 氨配 2 氧**（$\text{NH}_3 + 2\text{O}_2 \rightarrow \text{HNO}_3 + \text{H}_2\text{O}$）。

**第 2 步：计算 $\text{NH}_3$ 的物质的量（$\text{mol}$）**
- $\text{NH}_3$ 质量为 $6.8\text{ kg} = 6800\text{ g}$，摩尔质量为 $14 + 1 \times 3 = 17\text{ g/mol}$：
$$n(\text{NH}_3) = \frac{6800\text{ [g]}}{17\text{ [g/mol]}} = 400\text{ [mol]}$$

**第 3 步：计算生成的纯 $\text{HNO}_3$ 质量**
- 生成 $\text{HNO}_3$ 为 $400\text{ mol}$，其摩尔质量为 $1 + 14 + 16 \times 3 = 63\text{ g/mol}$：
$$m(\text{HNO}_3) = 63\text{ [g/mol]} \times 400\text{ [mol]} = 25200\text{ [g]}$$

**第 4 步：换算为质量分数 $60\%$ 的硝酸溶液质量**
$$m_{\text{溶液}} = 25200 \times \frac{100}{60} = 42000\text{ [g]} = 42\text{ [kg]}$$

##### 【最终答案】
**$42\text{ kg}$**

### 3.5 リン（15 族）の同素体と重要試薬の保存法（原书 P.104）

#### ① 黄リン（$\text{P}_4$）与赤リン（$\text{P}_x$）对比
| 项目 | **黄リン（$\text{P}_4$）** | **赤リン（$\text{P}_x$）** |
| :--- | :--- | :--- |
| 外观与状态 | 淡黄色・蜡状固体（ろう状固体） | 赤褐色・粉末（火柴盒侧面擦火皮） |
| 毒性 | **猛毒** | **無毒** |
| 发火性与保存 | 易**自然発火** $\rightarrow$ **水中保存** | 不自燃 |
| 分子结构 | 正四面体结构（$\text{P}_4$） | 网状高分子（網目状高分子） |
| 制法 | 磷矿石 + 硅砂 + 焦炭电炉加热：$2\text{Ca}_3(\text{PO}_4)_2 + 6\text{SiO}_2 + 10\text{C} \rightarrow 6\text{CaSiO}_3 + 10\text{CO} + \text{P}_4$ | 将黄磷在氮气中 $250^\circ\text{C}$ 加热数小时即得赤磷 |

#### ② EJU 必背：六大特殊试剂保存法速查表
| 試薬（试剂） | 特殊性质（原因） | **保存方法** |
| :--- | :--- | :--- |
| **黄リン（$\text{P}_4$）** | 空气中自然発火 | **水中** |
| **アルカリ金属（$\text{Na}, \text{K}$）** | 与空气中的 $\text{O}_2$ 及水剧烈反应 | **石油中** |
| **エーテル（乙醚）** | 极易挥发、易引火 | **火気なし冷所**（远离火源阴凉处） |
| **濃硝酸（$\text{HNO}_3$）** | 见光或受热分解 | **褐色びん**（棕色瓶、冷暗所） |
| **ハロゲン化銀（$\text{AgCl}, \text{AgBr}$ 等）** | 感光性（见光分解） | **褐色びん**（棕色瓶） |
| **フッ化水素酸（$\text{HF}$）** | 溶解玻璃（主成分 $\text{SiO}_2$） | **ポリエチレン容器**（聚乙烯塑料瓶） |

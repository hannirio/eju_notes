## 1. 本节前置：国内高中化学基础唤醒

本切片覆盖了日本高中有机高分子化学中**最核心的天然高分子全貌**（二糖海藻糖、多糖淀粉与纤维素、氨基酸与蛋白质、酶、核酸）以及**合成高分子的总分类与五大聚合机理**。

### 1.1 国内高中核心基础快速唤醒
1. **二糖与多糖的本质区别**
   - **二糖**（$\text{C}_{12}\text{H}_{22}\text{O}_{11}$）：由 2 分子单糖脱去 1 分子水缩合而成。是否具有**还原性**（能否发生银镜反应或与斐林试剂/新制 $\text{Cu(OH)}_2$ 反应），取决于分子中是否还保留着游离的**半缩醛羟基（ヘミアセタール構造）**。蔗糖（スクロース）和海藻糖（トレハロース）因为两个单糖的半缩醛羟基全部参与形成糖苷键，所以**无还原性**。
   - **多糖**（$(\text{C}_6\text{H}_{10}\text{O}_5)_n$）：淀粉、糖原、纤维素都是天然高分子，由于聚合度 $n$ 值不同，它们**都是混合物**（无固定熔沸点），且**互不为同分异构体**；多糖均**无还原性、无甜味**。
   - **淀粉 vs 纤维素**：淀粉由 **$\alpha$-葡萄糖** 缩聚而成（呈螺旋结构，遇碘变蓝/红紫）；纤维素由 **$\beta$-葡萄糖** 缩聚而成（呈直链纤维状，遇碘不变色）。
2. **纤维素的酯化与人造纤维**
   - 每个葡萄糖单元上保留有 **3 个游离羟基（$-\text{OH}$）**，因此纤维素可写作 $[\text{C}_6\text{H}_7\text{O}_2(\text{OH})_3]_n$。
   - 与浓硝酸/浓硫酸混酸发生**酯化反应**生成**硝酸纤维素（ニトロセルロース）**；与乙酸酐发生酯化生成**醋酸纤维素（アセチルセルロース）**。
3. **氨基酸的两性与等电点**
   - 组成蛋白质的天然氨基酸均为 **$\alpha$-氨基酸**：$\text{H}_2\text{N}-\text{CH}(\text{R})-\text{COOH}$。
   - 分子内既有碱性基团 $-\text{NH}_2$ 又有酸性基团 $-\text{COOH}$，在水溶液和晶体中会发生分子内酸碱中和，以**两性离子（双性イオン）** ${}^{+}\text{H}_3\text{N}-\text{CH}(\text{R})-\text{COO}^{-}$ 的形式存在。
   - 溶液 $\text{pH}$ 改变时，氨基酸在**阳离子 $\rightleftharpoons$ 两性离子 $\rightleftharpoons$ 阴离子**之间移动。当正负电荷总数恰好抵消、整体净电荷为 0 时的 $\text{pH}$ 称为**等电点（等電点）**。
4. **蛋白质的结构、性质与显色反应**
   - 氨基酸通过**脱水缩合**形成**肽键（$-\text{CO}-\text{NH}-$）**构成多肽与蛋白质。
   - **变性（変性）**：受热、强酸、强碱、重金属盐等作用，空间结构被破坏，失去生理活性，**不可逆**。
   - **盐析（塩析）**：加入大量轻金属盐（如 $\text{NaCl}$、$(\text{NH}_4)_2\text{SO}_4$）使溶解度降低而析出，加水可重新溶解，**可逆**。
   - **酶（酵素）**：本质是具有催化作用的蛋白质（生体触媒），具有**专一性（基質特異性）**、**最适温度**（约 $40^\circ\text{C}$，高温变性失活）和**最适 $\text{pH}$**。
5. **核酸（DNA 与 RNA）与五大聚合反应**
   - 核酸由**核苷酸（ヌクレオチド）**脱水缩合而成，每个核苷酸由**磷酸 + 五碳糖 + 含氮碱基**构成。DNA 含脱氧核糖（A/T/C/G，双螺旋），RNA 含核糖（A/U/C/G，单链）。
   - 合成高分子的聚合机理主要分为：**加聚（付加重合）**、**缩聚（縮合重合）**、**加成缩合（付加縮合）**、**开环聚合（開環重合）**与**共聚（共重合）**。

### 1.2 中日化学体系差异提醒（EJU 避坑必看）

1. **「必須アミノ酸」数量差异**：
   - 国内老教材常提“成人 8 种必需氨基酸（儿童加组氨酸共 9 种）”；**日本高中教材与 EJU 统一规定为 9 种类**（直接包含组氨酸ヒスチジン）。
2. **「ニトロセルロース」虽叫“硝基”，本质却是硝酸酯！**
   - 日本教材沿用历史惯用名 `ニトロセルロース`（Nitrocellulose），但请注意结构式是 $-\text{ONO}_2$（**硝酸酯**，不是碳原子直接连 $-\text{NO}_2$ 的硝基化合物！）。EJU 经常出判断题：“ニトロセルロースはニトロ化合物である（×，正しくは硝酸エステル）”。
3. **再生纤维 vs 半合成纤维的严格区分**：
   - **再生繊維（レーヨン，人造丝）**：纤维素仅经过溶解再析出，**化学成分仍是纤维素**（如銅アンモニアレーヨン、ビスコースレーヨン）。
   - **半合成繊維（アセテート）**：对天然纤维素进行了**化学改性（乙酰化）**，成分变为二醋酸纤维素（ジアセチルセルロース）。
4. **双缩脲反应（ビウレット反応）的判定门槛**：
   - 日本 EJU 明确考点：**ビウレット反応** 仅针对 **三肽（トリペプチド）及以上**（即分子中至少含有 **2 个肽键** 的多肽或蛋白质）才呈赤紫色！**二肽（ジペプチド，仅 1 个肽键）和单个氨基酸均不显色**。
5. **含硫氨基酸检测（硫黄の検出反応）的真题细节**：
   - 蛋白质加 $\text{NaOH}$ 加热后加醋酸铅(II) 生成黑色 $\text{PbS}$ 沉淀，在严谨的 EJU 真题中，**半胱氨酸（システイン，含 $-\text{SH}$）**呈阳性，而**蛋氨酸（メチオニン，含硫醚键 $-\text{S}-\text{CH}_3$）**由于硫醚键难以在碱中脱硫，通常**不显色**（需特别留意原教材与真题的细微差别）。

### 2.4 关键化学方程式与公式的日语课堂口语读法
1. **纤维素彻底硝化反应**：$[\text{C}_6\text{H}_7\text{O}_2(\text{OH})_3]_n + 3n\text{HNO}_3 \rightarrow [\text{C}_6\text{H}_7\text{O}_2(\text{ONO}_2)_3]_n + 3n\text{H}_2\text{O}$
   - 读法：`セルロース たす さんエヌ しょうさん やじるし トリニトロセルロース たす さんエヌ みず`
2. **纤维素乙酰化反应**：$[\text{C}_6\text{H}_7\text{O}_2(\text{OH})_3]_n + 3n(\text{CH}_3\text{CO})_2\text{O} \rightarrow [\text{C}_6\text{H}_7\text{O}_2(\text{OCOCH}_3)_3]_n + 3n\text{CH}_3\text{COOH}$
   - 读法：`セルロース たす さんエヌ むすいさくさん やじるし トリアセチルセルロース たす さんエヌ さくさん`
3. **中性氨基酸等电点氢离子浓度公式**：$[\text{H}^+] = \sqrt{K_1 K_2}$
   - 读法：`すいそイオンのうど イコール ルート ケーワン ケーつー`
4. **$\text{pH}$ 计算式**：$\text{pH} = -\log_{10}[\text{H}^+]$
   - 读法：`ピーエイチ イコール マイナス ログ じゅうてい すいそイオンのうど`

#### 【分步标准解答】

为书写简便，令：
- 阳离子 $\text{H}_3\text{N}^+-\text{CH}_2-\text{COOH}$ 的浓度为 $[\text{A}^+]$
- 两性离子 $\text{H}_3\text{N}^+-\text{CH}_2-\text{COO}^-$ 的浓度为 $[{}^{+}\text{B}^{-}]$
- 阴离子 $\text{H}_2\text{N}-\text{CH}_2-\text{COO}^-$ 的浓度为 $[\text{C}^-]$

**（1）求甘氨酸的等电点**
- **第 1 步**：写出两步电离平衡常数 $K_1$ 与 $K_2$ 的表达式，并分别解出 $[\text{A}^+]$ 和 $[\text{C}^-]$：
  - 由 $\text{A}^+ \rightleftharpoons {}^{+}\text{B}^{-} + \text{H}^+$ 得：
    $$K_1 = \frac{[{}^{+}\text{B}^{-}][\text{H}^+]}{[\text{A}^+]} \implies [\text{A}^+] = \frac{[{}^{+}\text{B}^{-}][\text{H}^+]}{K_1}$$
  - 由 ${}^{+}\text{B}^{-} \rightleftharpoons \text{C}^- + \text{H}^+$ 得：
    $$K_2 = \frac{[\text{C}^-][\text{H}^+]}{[{}^{+}\text{B}^{-}]} \implies [\text{C}^-] = \frac{K_2[{}^{+}\text{B}^{-}]}{[\text{H}^+]}$$
- **第 2 步**：利用等电点条件 $[\text{A}^+] = [\text{C}^-]$ 消去 $[{}^{+}\text{B}^{-}]$：
  $$\frac{[{}^{+}\text{B}^{-}][\text{H}^+]}{K_1} = \frac{K_2[{}^{+}\text{B}^{-}]}{[\text{H}^+]} \implies [\text{H}^+]^2 = K_1 K_2$$
- **第 3 步**：代入数据求 $[\text{H}^+]$ 与 $\text{pH}$：
  $$[\text{H}^+] = \sqrt{K_1 K_2} = \sqrt{4.0 \times 10^{-3} \times 2.5 \times 10^{-10}} = \sqrt{10 \times 10^{-13}} = \sqrt{10^{-12}} = 1.0 \times 10^{-6}\text{ mol/L}$$
  $$\text{pH} = -\log_{10}[\text{H}^+] = -\log_{10}(1.0 \times 10^{-6}) = 6.0$$

> 💡 **讲师批注**：在等电点时，双性离子 $[{}^{+}\text{B}^{-}]$ 自身正负电荷抵消（净电荷为 0），因此只要**阳离子浓度等于阴离子浓度（$[\text{A}^+] = [\text{C}^-]$）**，整个平衡混合物的净电荷就为 0！注意题目给出的 $K_1, K_2$ 均为 2 位有效数字，故等电点写作 **`6.0`**（而非 `6`）。

**（2）求 $\text{pH} = 1$ 水溶液中三种离子的摩尔浓度比**
- **第 1 步**：由 $\text{pH} = 1$ 确定氢离子浓度：
  $$[\text{H}^+] = 10^{-1}\text{ mol/L}$$
- **第 2 步**：利用 $K_1, K_2$ 分别求出相邻两种离子的浓度比：
  $$\frac{[{}^{+}\text{B}^{-}]}{[\text{A}^+]} = \frac{K_1}{[\text{H}^+]} = \frac{4.0 \times 10^{-3}}{10^{-1}} = 4.0 \times 10^{-2}$$
  $$\frac{[\text{C}^-]}{[{}^{+}\text{B}^{-}]} = \frac{K_2}{[\text{H}^+]} = \frac{2.5 \times 10^{-10}}{10^{-1}} = 2.5 \times 10^{-9}$$
- **第 3 步**：将两式相乘，求 $[\text{C}^-]$ 与 $[\text{A}^+]$ 之比：
  $$\frac{[\text{C}^-]}{[\text{A}^+]} = \frac{[{}^{+}\text{B}^{-}]}{[\text{A}^+]} \times \frac{[\text{C}^-]}{[{}^{+}\text{B}^{-}]} = (4.0 \times 10^{-2}) \times (2.5 \times 10^{-9}) = 10 \times 10^{-11} = 1.0 \times 10^{-10}$$
- **第 4 步**：整合为连比形式（以占比最大的 $[\text{A}^+]$ 为 1）：
  $$[\text{A}^+] : [{}^{+}\text{B}^{-}] : [\text{C}^-] = 1 : 4.0 \times 10^{-2} : 10^{-10}$$

> 💡 **讲师批注**：验证一下物理直觉！$\text{pH} = 1$ 是强酸性溶液，溶液中 $\text{H}^+$ 极多，勒夏特列原理告诉我们平衡被强烈推向最左端（阳离子 $\text{A}^+$），所以 $[\text{A}^+]$ 远大于 $[{}^{+}\text{B}^{-}]$，而 $[\text{C}^-]$ 更是微乎其微（仅 $10^{-10}$ 级别），完全符合化学直觉！

#### 【最终答案】
- （1）**$6.0$**
- （2）**$[\text{A}^+] : [{}^{+}\text{B}^{-}] : [\text{C}^-] = 1 : 4.0 \times 10^{-2} : 10^{-10}$**（或写作 **$1 : 4.0 \times 10^{-2} : 1.0 \times 10^{-10}$**）

> - **ナイロン 66** 是己二胺 + 己二酸脱水的 **縮合重合**；而 **ナイロン 6** 是环状的 $\varepsilon$-己内酰胺（$\varepsilon$-カプロラクタム）的 **開環重合**！两者一字之差，机理完全不同，是 EJU 合成高分子的头号陷阱。
> - **ヌクレオチド（核苷酸）** vs **ヌクレオシド（核苷）**：记住“**チ（Chi）** 比 **シ（Shi）** 多一个磷酸（リン酸）”——即 `ヌクレオチド = 五炭糖 + 塩基 + リン酸`，`ヌクレオシド = 五炭糖 + 塩基`。

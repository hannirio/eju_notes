## 1. 本节前置：国内高中化学基础唤醒

本切片是无机化学承上启下的黄金篇章：前半部分收尾**非金属元素**（磷的氧化物与磷酸、14 族的碳和硅），后半部分正式进入**金属元素**的核心腹地（碱金属、2 族元素、两性金属、配离子、过渡元素与铁的检验）。其中**索尔维法制纯碱**、**拜耳法+冰晶石熔融盐电解炼铝**、**配离子构型与颜色**、**$\text{Fe}^{2+}/\text{Fe}^{3+}$ 鉴别**均是 EJU 每年必考的超高频大题母题！

### 1.1 国内高中核心基础快速唤醒
1. **碳族元素（14 族：$\text{C}, \text{Si}$）**
   - **碳的同素异形体**：金刚石（正四面体共价晶体，极硬、不导电）与石墨（正六边形平面层状结构，层间靠分子间力结合、有自由移动电子，质软、导电）。无定形碳经活化增大表面积即为**活性炭**（脱色、除臭）。
   - **$\text{CO}$ 与 $\text{CO}_2$**：$\text{CO}$ 为无色有毒、难溶于水的中性气体，高温具有强还原性（高炉炼铁还原 $\text{Fe}_2\text{O}_3$）；$\text{CO}_2$ 微溶于水呈弱酸性，能使澄清石灰水变浑浊（通入过量则生成可溶性 $\text{Ca}(\text{HCO}_3)_2$ 再次变澄清）。
   - **$\text{Si}$ 与 $\text{SiO}_2$**：单质硅是与金刚石结构相同的半导体（芯片、太阳能电池）；$\text{SiO}_2$ 是高熔点共价晶体，不溶于水和一般酸，**唯独与氢氟酸 $\text{HF}$ 反应**（刻蚀玻璃）以及与强碱熔融反应生成硅酸钠（水玻璃）。
2. **碱金属（1 族除 $\text{H}$：$\text{Li}, \text{Na}, \text{K}, \text{Rb}, \text{Cs}$）**
   - 极易失 1 个电子，化学性质极活泼，必须**保存在煤油（石油）中**隔绝空气与水；工业只能用**熔融盐电解**制单质；与冷水剧烈反应生成强碱与 $\text{H}_2$。
   - **$\text{Na}_2\text{CO}_3$（纯碱/苏打）vs $\text{NaHCO}_3$（小苏打/重曹）**：两者均能与盐酸反应放 $\text{CO}_2$；$\text{Na}_2\text{CO}_3$ 热稳定且溶解度大、碱性强；$\text{NaHCO}_3$ 受热易分解生成 $\text{Na}_2\text{CO}_3 + \text{H}_2\text{O} + \text{CO}_2\uparrow$，溶解度较小。
3. **2 族元素（$\text{Be}, \text{Mg}, \text{Ca}, \text{Sr}, \text{Ba}$）与钙的转化**
   - 石灰石（$\text{CaCO}_3$）$\xrightarrow{\text{高温}}$ 生石灰（$\text{CaO}$）$\xrightarrow{+\text{H}_2\text{O}}$ 熟石灰（$\text{Ca}(\text{OH})_2$）$\xrightarrow{+\text{CO}_2}$ $\text{CaCO}_3\downarrow$ $\xrightarrow{\text{过量 }\text{CO}_2}$ $\text{Ca}(\text{HCO}_3)_2$。
   - 工业还可用生石灰与焦炭高温制电石（$\text{CaC}_2$），电石遇水生成乙炔（$\text{C}_2\text{H}_2$）。
4. **两性金属（$\text{Al}, \text{Zn}, \text{Sn}, \text{Pb}$）与铝的冶炼**
   - 单质、氧化物、氢氧化物**既能溶于强酸，又能溶于强碱**。
   - 铝在空气中表面形成致密 $\text{Al}_2\text{O}_3$ 保护膜，在**浓硝酸（及浓硫酸）中发生钝化（不動態）**。
   - **铝热反应（テルミット反応）**：$\text{Al}$ 粉与 $\text{Fe}_2\text{O}_3$ 点燃剧烈放热，温度达 $3000^\circ\text{C}$，用于焊接铁轨。
   - **炼铝**：铝土矿（ボーキサイト）先经强碱提纯得纯净氧化铝（アルミナ $\text{Al}_2\text{O}_3$），再加入助熔剂**冰晶石（$\text{Na}_3\text{AlF}_6$）**降低熔点后进行**熔融盐电解**。
5. **配离子（錯イオン）与过渡元素（遷移元素）**
   - 金属阳离子与提供孤电子对的分子/阴离子（配体，配位子）通过配位键形成**配离子**。
   - 过渡元素通性：均为金属、高熔点高密度、多变价、离子和化合物多有色、常作催化剂、易形成配离子。
   - **铁离子检验**：$\text{Fe}^{3+}$ 遇 $\text{KSCN}$ 溶液立即变**血红色**；遇 $\text{OH}^-$ 生成红褐色 $\text{Fe}(\text{OH})_3\downarrow$；$\text{Fe}^{2+}$ 遇 $\text{OH}^-$ 生成灰白/绿白色 $\text{Fe}(\text{OH})_2\downarrow$。

### 1.2 中日化学体系差异提醒（EJU 避坑必看！）

1. **「十酸化四リン（$\text{P}_4\text{O}_{10}$）」而非“五氧化二磷”**：
   - 国内教材习惯写 $\text{P}_2\text{O}_5$（五氧化二磷），但日本 EJU 严格按真实分子结构写作 **$\text{P}_4\text{O}_{10}$（十酸化四リン）**！写方程式时务必记住 $4\text{P} + 5\text{O}_2 \rightarrow \text{P}_4\text{O}_{10}$ 以及 $\text{P}_4\text{O}_{10} + 6\text{H}_2\text{O} \rightarrow 4\text{H}_3\text{PO}_4$。
2. **「アルカリ土類金属（碱土金属）」不包含 $\text{Be}$ 和 $\text{Mg}$！（超高频陷阱！）**：
   - 国内与 IUPAC 定义第 2 族全部为碱土金属；但**日本高中与 EJU 教材明确规定：碱土金属仅指 $\text{Ca}, \text{Sr}, \text{Ba}$（及 $\text{Ra}$），不包含 $\text{Be}$ 和 $\text{Mg}$**！原因是 $\text{Be}, \text{Mg}$ 无焰色反应、不与冷水反应、氢氧化物难溶而硫酸盐易溶，与 $\text{Ca}, \text{Sr}, \text{Ba}$ 性质截然相反。
3. **铝与强碱反应的产物写作 $\text{Na}[\text{Al}(\text{OH})_4]$（四羟基合铝酸钠）**：
   - 国内老教材常写偏铝酸钠 $\text{NaAlO}_2$，而**日本 EJU（以及国内新课标）统一写作配合物形式 $\text{Na}[\text{Al}(\text{OH})_4]$**（テトラヒドロキシドアルミン酸ナトリウム）。注意配平水分子的个数！
4. **「遷移元素（过渡元素）」仅指 3–11 族，不含 12 族（$\text{Zn}, \text{Cd}, \text{Hg}$）！**：
   - 日本教材把 **12 族（$\text{Zn}, \text{Cd}, \text{Hg}$）归类为典型元素（典型元素）**，只有 **3–11 族**叫过渡元素（遷移元素）！所以日本教材会强调“水溶液中典型元素的离子全都是无色的”（$\text{Zn}^{2+}$ 也确实无色）。
5. **氨碱法（アンモニアソーダ法 / ソルベー法）与国内“侯氏制碱法”的区别**：
   - EJU 考的是经典的**索尔维法（ソルベー法）**，副产物是**氯化钙 $\text{CaCl}_2$**（因为用熟石灰 $\text{Ca}(\text{OH})_2$ 回收 $\text{NH}_4\text{Cl}$ 中的 $\text{NH}_3$），不是国内常考的联碱法（副产 $\text{NH}_4\text{Cl}$ 化肥）。
6. **$\text{Fe}^{2+}$ 与 $\text{Fe}^{3+}$ 遇铁氰化钾/亚铁氰化钾的沉淀颜色**：
   - $\text{Fe}^{3+} + \text{K}_4[\text{Fe}(\text{CN})_6]$（黄血盐）$\rightarrow$ **濃青色沈殿（普鲁士蓝）**；
   - $\text{Fe}^{2+} + \text{K}_3[\text{Fe}(\text{CN})_6]$（赤血盐）$\rightarrow$ **濃青色沈殿（滕氏蓝）**。
   - 记住口诀：**“二配三（$\text{Fe}^{2+}$ 配 $\text{Fe(III)}$），三配二（$\text{Fe}^{3+}$ 配 $\text{Fe(II)}$），都是浓青色沉淀！”**

> ⚠️ **原教材印刷勘误提醒（讲师人工逐页核对 `page_0106.jpg`–`page_0120.jpg` 发现）**：
> 1. **原书 P.107（PDF 第 108 页）**：一氧化碳实验室制法①印为 `HCOOH --(H2SO4, 加熱)--> H2O + CO2↑`，属于**严重印刷错误**！甲酸脱水生成的是**一氧化碳 $\text{CO}\uparrow$**（若写成 $\text{CO}_2$ 连氧原子都不守恒）。正确应为：$\text{HCOOH} \xrightarrow{\text{濃H}_2\text{SO}_4,\ \text{加熱}} \text{H}_2\text{O} + \text{CO}\uparrow$。
> 2. **原书 P.109（PDF 第 110 页）**：水玻璃与盐酸反应印为 `Na2SiO3 + HCl → 2NaCl + H2SiO3`，**漏印 $\text{HCl}$ 前的配平系数 `2`**！正确应为：$\text{Na}_2\text{SiO}_3 + 2\text{HCl} \rightarrow 2\text{NaCl} + \text{H}_2\text{SiO}_3\downarrow$。
> 3. **原书 P.111（PDF 第 112 页）**：表格中 $\text{Na}_2\text{CO}_3$ 水解方程式印为 `CO3^2- + H2O ⇌ HCO3^- + OH^+`，**氢氧根电荷印反**！正确应为：$\text{CO}_3^{2-} + \text{H}_2\text{O} \rightleftharpoons \text{HCO}_3^- + \text{OH}^-$。
> 4. **原书 P.114（PDF 第 115 页）**：⑦ 烧石膏原书括号注为 `焼きセッコウ（液体状）` 易造成误解——烧石膏 $\text{CaSO}_4 \cdot \frac{1}{2}\text{H}_2\text{O}$ 本身是**白色固体粉末**，加水调和后才呈糊状流动体并放置硬化；且原式漏写脱去的 $\frac{3}{2}\text{H}_2\text{O}$。
> 5. **原书 P.115（PDF 第 116 页）**：铝的燃烧热化学方程式印为 `4Al + O2 = 2Al2O3 + 3314kJ`，**漏印 $\text{O}_2$ 前的系数 `3`**！正确应为：$4\text{Al} + 3\text{O}_2 = 2\text{Al}_2\text{O}_3 + 3314\text{ kJ}$。
> 6. **原书 P.116（PDF 第 117 页）**：
>    - 拜耳法①印为 `Al2O3 + 2NaOH + 3H2O → Na[Al(OH)4]`，**右侧漏印系数 `2`**（正确为 $2\text{Na}[\text{Al}(\text{OH})_4]$）；
>    - 拜耳法③印为 `Al(OH)3 → Al2O3 + 3H2O`，**左侧漏印系数 `2`**（正确为 $2\text{Al}(\text{OH})_3$）；
>    - 右侧中文注释 `氷晶石：冰晶石（六氟氯酸钠）` 为**错别字**，正确中文名为**六氟合铝酸钠**（$\text{Na}_3\text{AlF}_6$）。
> 7. **原书 P.119（PDF 第 120 页）**：过渡元素通性⑥印为 `様々な配位子と安定した錯イオンを作りたい。`（输入法误打），正确日语应为 **`作りやすい`**（容易形成稳定的配离子）。

## 2. 日文化学核心词汇、物质名称与假名注音（板书必备）

- **シュウ酸（しゅうさん / shūsan）** — 草酸/乙二酸（$(\text{COOH})_2$）
- **コークス（こーくす / kōkusu）** — 焦炭（$\text{C}$）
- **石灰石・大理石（せっかいせき・だいりせき / sekkaiseki, dairiseki）** — 石灰石・大理石（主成分 $\text{CaCO}_3$）

- **集積回路（しゅうせきかいろ / shūseki kairo）** — 集成电路（IC）

### 2.2 碱金属与 2 族元素（第六章 1–2 节）
- **アルカリ金属（あるかりきんぞく / arukari kinzoku）** — 碱金属（$\text{Li}, \text{Na}, \text{K}, \text{Rb}, \text{Cs}$）
- **融解塩電解（ゆうかいえんでんかい / yūkaien denkai）** — 熔融盐电解
- **炎色反応（えんしょくはんのう / enshoku hannō）** — 焰色反应
- **イオン交換膜法（いおんこうかんまくほう / ion kōkanmakuhō）** — 离子交换膜法（电解饱和食盐水制 $\text{NaOH}$）
- **炭酸ナトリウム（たんさんなとりうむ / tansan natoriumu）** — 碳酸钠/纯碱（$\text{Na}_2\text{CO}_3$）
- **炭酸水素ナトリウム・重曹（たんさんすいそなとりうむ・じゅうそう / tansan suiso natoriumu, jūsō）** — 碳酸氢钠/小苏打（$\text{NaHCO}_3$）
- **風解性（ふうかいせい / fūkaisei）** — 风化性（结晶水合物在空气中自然失去结晶水，如 $\text{Na}_2\text{CO}_3 \cdot 10\text{H}_2\text{O} \rightarrow \text{Na}_2\text{CO}_3 \cdot \text{H}_2\text{O}$）
- **アンモニアソーダ法・ソルベー法（あんもにあそーだほう・そるべーほう）** — 氨碱法/索尔维法
- **アルカリ土類金属（あるかりどるいきんぞく / arukari dorui kinzoku）** — 碱土金属（日本限定：$\text{Ca}, \text{Sr}, \text{Ba}$）
- **融雪剤（ゆうせつざい / yūsetsuzai）** — 融雪剂（$\text{CaCl}_2$）
- **造影剤（ぞうえいざい / zōeizai）** — X 射线造影剂/钡餐（$\text{BaSO}_4$）
- **にがり（にがり / nigari）** — 卤水（主成分 $\text{MgCl}_2$，点豆腐用）
- **耐火レンガ（たいかれんが / taika renga）** — 耐火砖（$\text{MgO}$，熔点 $2826^\circ\text{C}$）
- **生石灰・消石灰（せいせっかい・しょうせっかい / seisekkai, shōsekkai）** — 生石灰（$\text{CaO}$）・熟石灰（$\text{Ca}(\text{OH})_2$）
- **カーバイド（かーばいど / kābaido）** — 电石/碳化钙（$\text{CaC}_2$）
- **アセチレン（あせちれん / asechiren）** — 乙炔（$\text{C}_2\text{H}_2$）
- **セッコウ・焼きセッコウ（せっこう・やきせっこう / sekkō, yakisekkō）** — 石膏（$\text{CaSO}_4 \cdot 2\text{H}_2\text{O}$）・烧石膏（$\text{CaSO}_4 \cdot \frac{1}{2}\text{H}_2\text{O}$）
- **さらし粉（さらしこ / sarashiko）** — 漂白粉（$\text{CaCl}(\text{ClO}) \cdot \text{H}_2\text{O}$）

### 2.3 两性金属、配离子与过渡元素（第六章 3–5 节）
- **両性金属元素（りょうせいきんぞくげんそ / ryōsei kinzoku genso）** — 两性金属元素（$\text{Al}, \text{Zn}, \text{Sn}, \text{Pb}$）
- **不動態（ふどうたい / fudōtai）** — 钝化状态（表面形成致密氧化膜）
- **アルマイト（あるまいと / arumaito）** — 阳极氧化铝（人工加厚氧化铝保护膜）
- **テルミット反応（てるみっとはんのう / terumitto hannō）** — 铝热反应（$\text{Fe}_2\text{O}_3 + 2\text{Al} \rightarrow \text{Al}_2\text{O}_3 + 2\text{Fe}$）
- **ボーキサイト（ぼーきさいと / bōkisaito）** — 铝土矿（$\text{Al}_2\text{O}_3 \cdot n\text{H}_2\text{O}$）
- **アルミナ（あるみな / arumina）** — 氧化铝/刚玉（$\text{Al}_2\text{O}_3$）
- **氷晶石（ひょうしょうせき / hyōshōseki）** — 冰晶石（$\text{Na}_3\text{AlF}_6$，六氟合铝酸钠）
- **ミョウバン（みょうばん / myōban）** — 明矾（$\text{AlK}(\text{SO}_4)_2 \cdot 12\text{H}_2\text{O}$，复盐・正八面体结晶）
- **複塩（ふくえん / fukuen）** — 复盐
- **ジュラルミン（じゅらるみん / jurarumin）** — 硬铝/杜拉铝（$\text{Al} + \text{Cu}$ 合金，用于飞机机身）
- **ハンダ（はんだ / handa）** — 焊锡（$\text{Sn} + \text{Pb}$ 合金）

### 3.2 第六章 1 节：碱金属与索尔维法（含例题深度解析，原书 P.110–P.112）

#### ① 碱金属通性与焰色反应速记（原书 P.110）
- 熔点规律：原子序数越小熔点越高（$\text{Li} \gt \text{Na} \gt \text{K} \gt \text{Rb} \gt \text{Cs}$）；$\text{Li}, \text{Na}, \text{K}$ 密度小于水，浮于水面。
- 钠与水反应：$2\text{Na} + 2\text{H}_2\text{O} \rightarrow 2\text{NaOH} + \text{H}_2\uparrow$
- 工业制 $\text{NaOH}$（离子交换膜法电解饱和食盐水）：$2\text{NaCl} + 2\text{H}_2\text{O} \xrightarrow{\text{電気分解}} 2\text{NaOH} + \text{H}_2\uparrow + \text{Cl}_2\uparrow$
- **日本 EJU 必背焰色反应口诀（「リアカーなきK村、動力借りるとするもくれない、馬力で行こう」）**：
  - $\text{Li}$（赤）、$\text{Na}$（黄）、$\text{K}$（赤紫）、$\text{Cu}$（青緑/緑）、$\text{Ca}$（橙）、$\text{Sr}$（紅/深赤）、$\text{Ba}$（黄緑/緑）

#### ② $\text{Na}_2\text{CO}_3$ 与 $\text{NaHCO}_3$ 对比及索尔维法（原书 P.111）
- $\text{Na}_2\text{CO}_3$ 溶于水呈较强碱性（**已勘误电荷**）：$\text{CO}_3^{2-} + \text{H}_2\text{O} \rightleftharpoons \text{HCO}_3^- + \text{OH}^-$；受热不分解。
- $\text{NaHCO}_3$ 溶解度较小，呈弱碱性：$\text{HCO}_3^- + \text{H}_2\text{O} \rightleftharpoons \text{H}_2\text{CO}_3 + \text{OH}^-$；受热分解：$2\text{NaHCO}_3 \xrightarrow{\text{加熱}} \text{Na}_2\text{CO}_3 + \text{H}_2\text{O} + \text{CO}_2\uparrow$。
- **风化性（風解性）**：$\text{Na}_2\text{CO}_3 \cdot 10\text{H}_2\text{O}$（无色结晶）暴露在空气中自动失水变为 $\text{Na}_2\text{CO}_3 \cdot \text{H}_2\text{O}$（白色粉末）。

#### 📌 切片例题 1：索尔维法（アンモニアソーダ法）工业计算题（原书 P.112 / PDF 第 113 页）

#### 【原题重现与翻译】
> **原题**：
> アンモニアソーダ法で炭酸ナトリウムを $106\text{ kg}$ 得るには、何 $\text{kg}$ の塩化ナトリウムが必要か。$\text{NaCl} = 58.5$，$\text{Na}_2\text{CO}_3 = 106$
>
> **中文翻译**：

#### 【分步标准解答】

**第 1 步：写出索尔维法的 5 步反应并消元推导总合并式（合体式）**
- ① 主反应（先通 $\text{NH}_3$ 再通 $\text{CO}_2$，析出溶解度小的 $\text{NaHCO}_3$）：
  $$\text{NaCl} + \text{NH}_3 + \text{CO}_2 + \text{H}_2\text{O} \rightarrow \text{NH}_4\text{Cl} + \text{NaHCO}_3\downarrow$$
- ② 主反应（加热分解 $\text{NaHCO}_3$）：
  $$2\text{NaHCO}_3 \xrightarrow{\text{加熱}} \text{Na}_2\text{CO}_3 + \text{H}_2\text{O} + \text{CO}_2\uparrow$$
- ③ 副反应（煅烧石灰石制 $\text{CO}_2$ 与 $\text{CaO}$）：
  $$\text{CaCO}_3 \xrightarrow{\text{加熱}} \text{CaO} + \text{CO}_2\uparrow$$
- ④ 副反应（生石灰加水制熟石灰）：
  $$\text{CaO} + \text{H}_2\text{O} \rightarrow \text{Ca}(\text{OH})_2$$
- ⑤ 副反应（强碱制弱碱，回收 $\text{NH}_3$ 循环使用）：
  $$2\text{NH}_4\text{Cl} + \text{Ca}(\text{OH})_2 \rightarrow \text{CaCl}_2 + 2\text{NH}_3\uparrow + 2\text{H}_2\text{O}$$
- 将 **① $\times 2$ $+$ ② $+$ ③ $+$ ④ $+$ ⑤** 左右相加消去全部中间产物（$2\text{NaHCO}_3$、$2\text{NH}_4\text{Cl}$、$\text{CaO}$、$\text{Ca}(\text{OH})_2$、$2\text{NH}_3$、$2\text{CO}_2$、$3\text{H}_2\text{O}$），得到**总合并式**：
  $$\text{CaCO}_3 + 2\text{NaCl} \rightarrow \text{Na}_2\text{CO}_3 + \text{CaCl}_2$$

> 💡 **讲师批注**：考试中如果不考中间步骤，直接利用**钠元素守恒**也能 1 秒得出比例关系：$2\text{NaCl} \sim \text{Na}_2\text{CO}_3$！即每生成 $1\text{ mol}$ $\text{Na}_2\text{CO}_3$，理论上必消耗 $2\text{ mol}$ $\text{NaCl}$。同时务必记住反应①中**必须先通溶解度极大的 $\text{NH}_3$ 使溶液呈碱性，再通 $\text{CO}_2$** 才能大量吸收 $\text{CO}_2$ 析出 $\text{NaHCO}_3$ 沉淀！

**第 2 步：计算所需生成的 $\text{Na}_2\text{CO}_3$ 的物质的量**
- 将质量单位统一换算为 $\text{g}$：$106\text{ kg} = 106000\text{ g} = 1.06 \times 10^5\text{ g}$。
- 物质的量：
  $$n(\text{Na}_2\text{CO}_3) = \frac{106000\text{ [g]}}{106\text{ [g/mol]}} = 1000\text{ [mol]}$$

**第 3 步：按化学计量数之比求所需 $\text{NaCl}$ 的物质的量与质量**
- 由合体式 $\text{CaCO}_3 + 2\text{NaCl} \rightarrow \text{Na}_2\text{CO}_3 + \text{CaCl}_2$ 可知：
  $$n(\text{NaCl}) = 2 \times n(\text{Na}_2\text{CO}_3) = 2 \times 1000 = 2000\text{ [mol]}$$
- 所需 $\text{NaCl}$ 的质量：
  $$m(\text{NaCl}) = 2000\text{ [mol]} \times 58.5\text{ [g/mol]} = 117000\text{ [g]} = 117\text{ [kg]}$$

> 💡 **讲师批注**：有效数字核对：题目给出的 $106\text{ kg}$、$58.5$、$106$ 均为 **3 位有效数字**，计算结果 $117\text{ kg}$ 恰好为 3 位有效数字，完美精确！

#### 【最终答案】
**$117\text{ kg}$**

- **配平后的拜耳法 3 步方程式（已勘误补齐全部系数）**：
  1. 碱溶除杂：$\text{Al}_2\text{O}_3 + 2\text{NaOH} + 3\text{H}_2\text{O} \rightarrow 2\text{Na}[\text{Al}(\text{OH})_4]$
  2. 水解析出：$\text{Na}[\text{Al}(\text{OH})_4] \rightarrow \text{Al}(\text{OH})_3\downarrow + \text{NaOH}$
  3. 强热灼烧：$2\text{Al}(\text{OH})_3 \xrightarrow{1200^\circ\text{C}} \text{Al}_2\text{O}_3 + 3\text{H}_2\text{O}$
- **相关重要物质速查（原书 P.116–P.117）**：
  - **铅（$\text{Pb}$）**：表面生成难溶 $\text{PbCl}_2$、$\text{PbSO}_4$ 保护膜，故**不溶于稀盐酸、稀硫酸**；$\text{PbO}_2$（褐色）具强氧化性，作铅蓄电池正极；$\text{SnCl}_2$ 具强还原性（$+2 \rightarrow +4$）。
  - **明矾（ミョウバン $\text{AlK}(\text{SO}_4)_2 \cdot 12\text{H}_2\text{O}$）**：正八面体复盐结晶，水溶液呈**弱酸性**（$\text{Al}^{3+}$ 水解）。
  - **防锈镀层必考对比**：**トタン（白铁皮，$\text{Fe}$ 镀 $\text{Zn}$）**因 $\text{Zn}$ 比 $\text{Fe}$ 更活泼，刮伤后 $\text{Zn}$ 牺牲自己保护铁（适合室外屋顶）；**ブリキ（马口铁，$\text{Fe}$ 镀 $\text{Sn}$）**因 $\text{Fe}$ 比 $\text{Sn}$ 活泼，一旦刮伤铁会加速生锈（适合罐头内壁）。

### 3.6 第六章 4–5 节：过渡元素与铁离子鉴别表（原书 P.119）

- **过渡元素（3–11 族）6 大通性**：① 周期表相邻元素性质相似（全为金属）；② 熔点高、硬、密度大（钨 $\text{W}$ 熔点最高 $3410^\circ\text{C}$）；③ 多变价（高氧化态常作氧化剂）；④ 离子和化合物多有色；⑤ 常作催化剂（$\text{Pt}, \text{V}_2\text{O}_5, \text{MnO}_2$）或具强磁性（$\text{Fe}, \text{Co}, \text{Ni}$）；⑥ 易与配体形成稳定配离子（原书「作りたい」应为「作りやすい」）。
- **$\text{Fe}^{2+}$ 与 $\text{Fe}^{3+}$ 鉴别终极速查表（原书 P.119 必背！）**：

| 检测试剂水溶液 | $\text{Fe}^{2+}$（水溶液：**淡緑色**） | $\text{Fe}^{3+}$（水溶液：**黄褐色**） |
| :--- | :---: | :---: |
| **$\text{OH}^-$（如 $\text{NaOH}$）** | $\text{Fe}(\text{OH})_2\downarrow$（**緑白色沉淀**） | $\text{Fe}(\text{OH})_3\downarrow$（**赤褐色沉淀**） |
| **$\text{K}_4[\text{Fe}(\text{CN})_6]$（黄血盐）** | $\triangle$（青白色沉淀，不作主鉴别） | **濃青色沈殿**（普鲁士蓝） |
| **$\text{K}_3[\text{Fe}(\text{CN})_6]$（赤血盐）** | **濃青色沈殿**（滕氏蓝） | $\triangle$（褐色溶液，无沉淀） |
| **$\text{KSCN}$（硫氰酸钾）** | $\times$（无变化） | **血赤色水溶液**（极灵敏！） |

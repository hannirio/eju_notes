  - 点 $P$ における接線：$x_1 x + y_1 y = 9$
  - 点 $Q$ における接線：$x_2 x + y_2 y = 9$
  > 💡 讲师批注：本题与 `演習問題 2-(4)` 异曲同工！切忌试图解出 $P, Q$ 的具体坐标（带巨大根号），利用“两点同时满足同一线性方程”的同构思想，5 行秒杀！

  $$5x_2 + 6y_2 = 9 \quad \cdots \text{②}$$

  $$5x + 6y = 9$$

- **【分步标准解答】**
  放物線 $y = x^2 + a$ ① と円 $x^2 + y^2 = 9$ ② の連立方程式を考える。
  ① を ② に代入して $y$ を消去すると、
  $$x^2 + (x^2 + a)^2 = 9$$
  $$x^4 + (2a + 1)x^2 + (a^2 - 9) = 0 \quad \cdots \text{③}$$
  ここで $t = x^2 \; (t \ge 0)$ とおくと、③ は次の $t$ の 2 次方程式になる。
  $$t^2 + (2a + 1)t + (a^2 - 9) = 0 \quad \cdots \text{④}$$
  > 💡 讲师批注：令 $t = x^2 \ge 0$ 是处理抛物线与圆对称交点问题的“降维打击”神技！对应关系一目了然：
  > - $t > 0$ の解 1 個 $\iff$ 異なる 2 個の $x$（$x = \pm\sqrt{t}$）
  > - $t = 0$ の解 $\iff$ $x = 0$（重解！即抛物线顶点 $(0, a)$ 与圆在 $y$ 轴上共享水平切线！）
  > - $t < 0$ の解 $\iff$ 対応する実数 $x$ はなし。

  **[1]** 放物線 ① と円 ② が接するのは、③ が実数重解をもつとき、すなわち次の (i) または (ii) の場合である。
  - **(i) $x = 0$（頂点 $(0, a)$）で接するとき（$t = 0$ が ④ の解）**：
    ④ に $t = 0$ を代入して、
    $$a^2 - 9 = 0 \implies a = \pm 3$$
    - $a = 3$ のとき：③ は $x^2(x^2 + 7) = 0$ となり、点 $(0, 3)$ で外接する。
    - $a = -3$ のとき：③ は $x^2(x^2 - 5) = 0$ となり、点 $(0, -3)$ で内接する（同時に 2 点 $(\pm\sqrt{5}, 2)$ でも交わる）。
  - **(ii) $x \neq 0$ の 2 点で同時（対称）に接するとき（④ が正の重解 $t > 0$ をもつ）**：
    ④ の判別式を $D$ とすると、
    $$D = (2a + 1)^2 - 4(a^2 - 9) = 4a^2 + 4a + 1 - 4a^2 + 36 = 4a + 37$$
    $D = 0$ より、$a = -\dfrac{37}{4}$。
    このとき、④ の重解は $t = -\dfrac{2a + 1}{2} = -\dfrac{-\frac{37}{2} + 1}{2} = \dfrac{35}{4} > 0$ となり条件を満たす（$x = \pm\dfrac{\sqrt{35}}{2}$ の 2 点で接する）。
  > 💡 讲师批注：高危易错点！如果只消去 $x^2$ 得到 $y^2 + y - (a+9) = 0$ 再直接令判别式 $D=0$，90% 的学生会只算出 $a = -\frac{37}{4}$ 而漏掉顶点相切的 $a = 3$ 和 $a = -3$！用 $x^4$ 方程或结合图像思考，绝不漏解！

  以上 (i), (ii) より、$a = -\dfrac{37}{4}, \; \pm 3$。

  **[2]** 放物線と円が異なる 4 個の交点をもつための必要十分条件は、$x$ の 4 次方程式 ③ が異なる 4 個の実数解をもつこと、すなわち $t$ の 2 次方程式 ④ が**異なる 2 つの正の実数解**をもつことである。
  ④ の 2 解を $t_1, t_2$ とすると、その必要十分条件は次の 3 式が同時に成り立つことである。
  1. $D > 0 \iff 4a + 37 > 0 \iff a > -\dfrac{37}{4}$
  2. $t_1 + t_2 > 0 \iff -(2a + 1) > 0 \iff a < -\dfrac{1}{2}$
  3. $t_1 t_2 > 0 \iff a^2 - 9 > 0 \iff a < -3 \text{ または } a > 3$

  これら 3 つの共通範囲をとると、
  $$-\frac{37}{4} < a < -3$$
- **【最终答案】**
  **[1] $a = -\dfrac{37}{4}, \; \pm 3$；[2] $-\dfrac{37}{4} < a < -3$**

### 演習問題 5（2 つの円・円束・共通接線）

#### 演習問題 5-(1)
- **【原题重现与翻译】**
  - 原题：2 つの円 $x^2 + y^2 = 5$……①，$x^2 + y^2 + 4x - 4y - 1 = 0$……② について
    - [1] 2 円の共有点の座標を求めよ。
    - [2] 2 円の共有点と点 $(1, 0)$ を通る円の中心と半径を求めよ。
  - 中文：关于两个圆 $x^2 + y^2 = 5$……①，$x^2 + y^2 + 4x - 4y - 1 = 0$……②：
    - [1] 求两圆公共点的坐标。
    - [2] 求经过两圆公共点及点 $(1, 0)$ 的圆的圆心与半径。
- **【考点定位】**
  - 两圆相交公共弦方程、圆系方程 $kf(x,y) + g(x,y) = 0$ 的应用。
- **【分步标准解答】**
  **[1]** ① を $x^2 + y^2 - 5 = 0$ と変形し、② から ① を辺々引くと（$x^2, y^2$ を消去）、
  $$(x^2 + y^2 + 4x - 4y - 1) - (x^2 + y^2 - 5) = 0$$
  $$4x - 4y + 4 = 0 \implies y = x + 1 \quad \cdots \text{③}$$
  > 💡 讲师批注：两圆方程直接相减消去二次项，立即得到公共弦所在直线方程 $y = x + 1$。

  ③ を ① に代入して、
  $$x^2 + (x + 1)^2 = 5$$
  $$2x^2 + 2x - 4 = 0 \implies x^2 + x - 2 = 0$$
  $$(x + 2)(x - 1) = 0 \implies x = -2, \; 1$$
  ③ より、
  - $x = -2$ のとき $y = -2 + 1 = -1$
  - $x = 1$ のとき $y = 1 + 1 = 2$
  よって、共有点の座標は $(-2, -1), \; (1, 2)$。

  **[2]** 2 円 ①，② の共有点を通る図形の方程式は、定数 $k$ を用いて次のように表せる（ただし円 ① を除く）。
  $$k(x^2 + y^2 - 5) + (x^2 + y^2 + 4x - 4y - 1) = 0 \quad \cdots \text{④}$$
  > 💡 讲师批注：验查一下点 $(1,0)$ 是否在被除外的圆 ① 上：$1^2 + 0^2 = 1 \neq 5$，不在圆 ① 上，所以所求圆一定能用圆系方程 ④ 表示！

  ④ が点 $(1, 0)$ を通るから、$x = 1, \; y = 0$ を代入すると、
  $$k(1 + 0 - 5) + (1 + 0 + 4 - 0 - 1) = 0$$
  $$-4k + 4 = 0 \implies k = 1$$
  $k = 1$ を ④ に代入して整理すると、
  $$2x^2 + 2y^2 + 4x - 4y - 6 = 0$$
  両辺を $2$ で割って、
  $$x^2 + y^2 + 2x - 2y - 3 = 0$$
  平方完成して基本形に直すと、
  $$(x + 1)^2 - 1 + (y - 1)^2 - 1 - 3 = 0$$
  $$(x + 1)^2 + (y - 1)^2 = 5$$
  よって、中心は $(-1, 1)$、半径は $\sqrt{5}$ である。
- **【最终答案】**
  **[1] $(-2, -1), \; (1, 2)$；[2] 中心 $(-1, 1)$、半径 $\sqrt{5}$**

#### 演習問題 5-(2)
- **【原题重现与翻译】**
  - 原题：円 $x^2 + y^2 = 25$ と直線 $y = x + 1$ の 2 つの交点と原点 $O$ を通る円の方程式を求めよ。
  - 中文：求经过圆 $x^2 + y^2 = 25$ 与直线 $y = x + 1$ 的两个交点以及原点 $O$ 的圆的方程。
- **【考点定位】**
  - 过圆与直线交点的圆系方程：$(x^2 + y^2 - r^2) + k(ax + by + c) = 0$。
- **【分步标准解答】**
  円 $x^2 + y^2 - 25 = 0$ と直線 $x - y + 1 = 0$ の 2 つの交点を通る円の方程式は、定数 $k$ を用いて次のように表せる。
  $$(x^2 + y^2 - 25) + k(x - y + 1) = 0 \quad \cdots \text{①}$$
  > 💡 讲师批注：因为 ① 中 $x^2, y^2$ 系数恒为 $1$，它表示过交点的所有圆，完全不需要把交点那堆带根号的坐标解出来！

  ① が原点 $O(0, 0)$ を通るから、$x = 0, \; y = 0$ を代入して、
  $$(0 + 0 - 25) + k(0 - 0 + 1) = 0 \implies -25 + k = 0 \implies k = 25$$
  $k = 25$ を ① に代入すると、
  $$x^2 + y^2 - 25 + 25(x - y + 1) = 0$$
  $$x^2 + y^2 + 25x - 25y = 0$$
  > 💡 讲师批注：验算！将 $x-y=-1$ 与 $x^2+y^2=25$ 代入结果：$25 + 25(-1) = 0$ ✓，且过 $(0,0)$ ✓，完美！
- **【最终答案】**
  **$x^2 + y^2 + 25x - 25y = 0$**

#### 演習問題 5-(3)
- **【原题重现与翻译】**
  - 原题：円 $x^2 + y^2 - 2kx - 4ky + 16k - 16 = 0$ は定数 $k$ の値に関わらず 2 点を通る。この 2 点の座標を求めよ。
  - 中文：圆 $x^2 + y^2 - 2kx - 4ky + 16k - 16 = 0$ 不论常数 $k$ 取何值都恒过两点，求这两点的坐标。
- **【考点定位】**
  - 含参圆系恒过定点问题（按参数 $k$ 整理为圆 + $k \times$ 直线 $= 0$）。
- **【分步标准解答】**
  与えられた円の方程式を $k$ について整理すると、
  $$(x^2 + y^2 - 16) + k(-2x - 4y + 16) = 0$$
  これが $k$ の値に関わらず成り立つための必要十分条件は、
  $$\begin{cases} x^2 + y^2 - 16 = 0 & \cdots \text{①} \\ -2x - 4y + 16 = 0 & \cdots \text{②} \end{cases}$$
  ② を $-2$ で割って整理すると、$x + 2y - 8 = 0 \implies x = 8 - 2y \quad \cdots \text{②'}$。
  ②' を ① に代入すると、
  $$(8 - 2y)^2 + y^2 - 16 = 0$$
  $$(64 - 32y + 4y^2) + y^2 - 16 = 0$$
  $$5y^2 - 32y + 48 = 0$$
  たすき掛けにより因数分解すると、
  $$(5y - 12)(y - 4) = 0 \implies y = \frac{12}{5}, \; 4$$
  > 💡 讲师批注：十字相乘分解 $5y^2 - 32y + 48$：把 $48$ 拆成 $(-12) \times (-4)$，交叉相加 $5(-4) + 1(-12) = -20 - 12 = -32$，一击命中！

  ②' に代入して、
  - $y = 4$ のとき：$x = 8 - 2(4) = 0$
  - $y = \dfrac{12}{5}$ のとき：$x = 8 - 2 \cdot \dfrac{12}{5} = \dfrac{40 - 24}{5} = \dfrac{16}{5}$
  よって、求める 2 点の座標は $(0, 4), \; \left(\dfrac{16}{5}, \dfrac{12}{5}\right)$。
- **【最终答案】**
  **$(0, 4), \; \left(\dfrac{16}{5}, \dfrac{12}{5}\right)$**

  $$x_1^2 + y_1^2 = 4 \quad \cdots \text{①}$$

  $$x_1 x + y_1 y - 4 = 0 \quad \cdots \text{②}$$

  直線 ② が円 $C_2$（中心 $(5, 0)$、半径 $1$）にも接するための条件は、点 $(5, 0)$ と直線 ② の距離が $1$ であることであるから、
  $$\frac{|5x_1 + 0 \cdot y_1 - 4|}{\sqrt{x_1^2 + y_1^2}} = 1$$
  ① より $\sqrt{x_1^2 + y_1^2} = 2$ であるから、
  $$\frac{|5x_1 - 4|}{2} = 1 \implies |5x_1 - 4| = 2$$
  $$5x_1 - 4 = \pm 2 \implies x_1 = \frac{6}{5} \text{ または } x_1 = \frac{2}{5}$$

  - **(i) $x_1 = \dfrac{6}{5}$ のとき（共通内接線）**：

    $$y_1^2 = 4 - \left(\frac{6}{5}\right)^2 = 4 - \frac{36}{25} = \frac{64}{25} \implies y_1 = \pm\frac{8}{5}$$

    $$\frac{6}{5}x \pm \frac{8}{5}y - 4 = 0 \implies 3x \pm 4y - 10 = 0$$

#### 演習問題 6-(2)
- **【原题重现与翻译】**
  - 原题：2 点 $A(6, 0), B(3, 3)$ と円 $x^2 + y^2 = 9$ 上を動く点を 3 つの頂点とする三角形の重心 $P$ を求めよ。
  - 中文：求以两点 $A(6, 0), B(3, 3)$ 和圆 $x^2 + y^2 = 9$ 上的动点为三个顶点的三角形的重心 $P$ 的轨迹。
- **【考点定位】**
  - 連動点（相关点法/代入法）求轨迹 + **三角形存在性（三点不共线）检验**。
- **【分步标准解答】**
  円 $x^2 + y^2 = 9$ 上を動く点を $Q(s, t)$、$\triangle ABQ$ の重心を $P(x, y)$ とする。
  点 $Q$ は円上にあるから、
  $$s^2 + t^2 = 9 \quad \cdots \text{①}$$
  また、重心の公式より、
  $$x = \frac{6 + 3 + s}{3} = 3 + \frac{s}{3}, \qquad y = \frac{0 + 3 + t}{3} = 1 + \frac{t}{3}$$
  これらを $s, t$ について解くと、
  $$s = 3x - 9 = 3(x - 3), \qquad t = 3y - 3 = 3(y - 1) \quad \cdots \text{②}$$
  > 💡 讲师批注：相关点法核心口诀——“要求谁的轨迹，就设谁为 $(x, y)$；把已知动点 $(s, t)$ 用 $(x, y)$ 反解出来，代入已知方程！”

  ② を ① に代入すると、
  $$\{3(x - 3)\}^2 + \{3(y - 1)\}^2 = 9$$
  $$9(x - 3)^2 + 9(y - 1)^2 = 9$$
  両辺を $9$ で割って、
  $$(x - 3)^2 + (y - 1)^2 = 1 \quad \cdots \text{③}$$

  ここで、3 点 $A, B, Q$ が三角形を作るためには、点 $Q$ が直線 $AB$ 上にないことが必要である。
  直線 $AB$ の方程式は、$y - 0 = \dfrac{3 - 0}{3 - 6}(x - 6) \implies x + y - 6 = 0$ である。
  円 $x^2 + y^2 = 9$ の中心 $(0, 0)$ と直線 $AB$ の距離 $d$ は、
  $$d = \frac{|0 + 0 - 6|}{\sqrt{1^2 + 1^2}} = \frac{6}{\sqrt{2}} = 3\sqrt{2} > 3 \text{（円の半径）}$$
  であるから、円 $x^2 + y^2 = 9$ と直線 $AB$ は共有点を持たない。
  > 💡 讲师批注：极其关键的满分检查！做三角形重心轨迹题时，一定要检查直线 $AB$ 是否与圆相交。如果相交，交点对应的重心必须挖掉（除外点）；本题 $d = 3\sqrt{2} > 3$ 表明相离，所以圆上**所有点**都能构成三角形，轨迹是完整的圆！

  よって、円 ① 上のすべての点 $Q$ に対して $\triangle ABQ$ が成り立ち、逆に円 ③ 上の任意の点 $P$ は条件を満たす。
  したがって、求める点 $P$ の軌跡は**中心 $(3, 1)$、半径 $1$ の円**である。
- **【最终答案】**
  **中心 $(3, 1)$、半径 $1$ の円（方程式：$(x - 3)^2 + (y - 1)^2 = 1$）**

#### 演習問題 6-(3)
- **【原题重现与翻译】**
  - 原题：次の直線の方程式を求めよ。
    - [1] 2 直線 $4x + 3y - 8 = 0, \; 5y + 3 = 0$ のなす角の二等分線。
    - [2] 直線 $l: x - y + 1 = 0$ に関して直線 $2x + y - 2 = 0$ と対称な直線。
  - 中文：求下列直线的方程：
    - [1] 两直线 $4x + 3y - 8 = 0, \; 5y + 3 = 0$ 的夹角平分线。
    - [2] 关于直线 $l: x - y + 1 = 0$ 与直线 $2x + y - 2 = 0$ 对称的直线。
- **【考点定位】**
  - 轨迹法求两直线夹角平分线（到两直线等距离）、轨迹法（动点转移法）求对称直线。
- **【分步标准解答】**
  **[1]** 求める二等分線上の任意の点を $P(x, y)$ とする。
  点 $P$ は 2 直線 $4x + 3y - 8 = 0$ と $5y + 3 = 0$ から等距離にあるから、点と直線の距離の公式より、
  $$\frac{|4x + 3y - 8|}{\sqrt{4^2 + 3^2}} = \frac{|0 \cdot x + 5y + 3|}{\sqrt{0^2 + 5^2}}$$
  $$\frac{|4x + 3y - 8|}{5} = \frac{|5y + 3|}{5}$$
  $$|4x + 3y - 8| = |5y + 3|$$
  絶対値を外すと、$4x + 3y - 8 = \pm(5y + 3)$。
  - 複号 $+$ のとき：$4x + 3y - 8 = 5y + 3 \implies 4x - 2y - 11 = 0$
  - 複号 $-$ のとき：$4x + 3y - 8 = -5y - 3 \implies 4x + 8y - 5 = 0$
  > 💡 讲师批注：必考常识验算！两条相交直线的两条角平分线一定**互相垂直**！检验斜率：$4x - 2y - 11 = 0$ 斜率为 $2$，$4x + 8y - 5 = 0$ 斜率为 $-\frac{1}{2}$，乘积 $2 \times (-\frac{1}{2}) = -1$，100% 垂直！

  **[2]** 求める対称な直線上の任意の点を $P(x, y)$ とし、直線 $l: x - y + 1 = 0$ に関して点 $P$ と対称な点を $Q(s, t)$ とおく。
  - 垂直条件（$PQ \perp l$）：$l$ の傾きは $1$ であるから、$\dfrac{t - y}{s - x} \cdot 1 = -1 \implies s + t = x + y \quad \cdots \text{①}$
  - 中点条件（線分 $PQ$ の中点が $l$ 上にある）：
    $$\frac{s + x}{2} - \frac{t + y}{2} + 1 = 0 \implies s - t = y - x - 2 \quad \cdots \text{②}$$
  ① $+$ ② より $2s = 2y - 2 \implies s = y - 1$。
  ① $-$ ② より $2t = 2x + 2 \implies t = x + 1$。
  > 💡 讲师批注：由于对称轴 $l: y = x + 1$ 斜率为 $1$，直接反解出 $s = y - 1, \; t = x + 1$。这种“动点转移法”可以通杀任何曲线（包括圆、抛物线）关于直线的对称方程！

  点 $Q(s, t)$ は直線 $2x + y - 2 = 0$ 上の点であるから、$2s + t - 2 = 0$ に代入して、
  $$2(y - 1) + (x + 1) - 2 = 0$$
  $$x + 2y - 3 = 0$$
- **【最终答案】**
  **[1] $4x - 2y - 11 = 0, \; 4x + 8y - 5 = 0$；[2] $x + 2y - 3 = 0$**

- **【分步标准解答】**
  **[1]** $y = x^2$ と $y = m(x - 1)$ から $y$ を消去すると、
  $$x^2 = m(x - 1) \implies x^2 - mx + m = 0 \quad \cdots \text{①}$$
  放物線と直線が異なる 2 点 $A, B$ で交わるための必要十分条件は、2 次方程式 ① が異なる 2 つの実数解をもつことである。
  ① の判別式を $D$ とすると、
  $$D = (-m)^2 - 4 \cdot 1 \cdot m = m^2 - 4m = m(m - 4) > 0$$
  よって、$m < 0, \; m > 4$。

  **[2]** 2 交点 $A, B$ の $x$ 座標をそれぞれ $\alpha, \beta$ とし、線分 $AB$ の中点を $P(x, y)$ とおく。
  $\alpha, \beta$ は ① の 2 解であるから、解と係数の関係より、
  $$\alpha + \beta = m$$
  中点 $P$ の $x$ 座標は、
  $$x = \frac{\alpha + \beta}{2} = \frac{m}{2} \implies m = 2x \quad \cdots \text{②}$$
  また、中点 $P(x, y)$ は直線 $y = m(x - 1)$ 上にあるから、② を代入して、
  $$y = 2x(x - 1) = 2x^2 - 2x$$
  > 💡 讲师批注：神级省时技巧！求弦中点的 $y$ 坐标时，千万不要用 $\frac{\alpha^2+\beta^2}{2}$ 去展开，直接利用“**中点 $P$ 必在弦所在直线 $y = m(x-1)$ 上**”代入 $m = 2x$，一步出结果！

  ここで、[1] より $m$ の存在範囲は $m < 0, \; m > 4$ であるから、② を用いて $x$ の範囲に変換すると、
  $$2x < 0 \text{ または } 2x > 4 \implies x < 0, \; x > 2$$
  逆に、放物線 $y = 2x^2 - 2x$ の $x < 0, \; x > 2$ の部分上の任意の点 $(x, y)$ に対して、$m = 2x$ とおけば $m < 0, \; m > 4$ となり、対応する異なる 2 交点 $A, B$ が存在してその中点が $(x, y)$ となる。
  よって、求める軌跡は**放物線 $y = 2x^2 - 2x$ の $x < 0, \; x > 2$ の部分**である。
- **【最终答案】**
  **[1] $m < 0, \; m > 4$；[2] 放物線 $y = 2x^2 - 2x$ の $x < 0, \; x > 2$ の部分**

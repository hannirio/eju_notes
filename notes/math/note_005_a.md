## 一、国内高中基础知识点唤醒与 EJU 考纲差异对比

本切片（P61–P75）横跨日本高中 **数学Ⅰ（二次関数・二次方程式・二次不等式）** 的收官压轴部分，以及 **数学Ⅱ（指数関数と対数関数）** 的开篇基础部分，涵盖五大核心知识板块。

### 1.1 二次函数图像与 $x$ 轴、直线的位置关系（グラフと二次方程式）

- **与 $x$ 轴的共有点**：二次函数 $y = ax^2 + bx + c\;(a \neq 0)$ 的图像与 $x$ 轴共有点的 $x$ 坐标，即为二次方程 $ax^2 + bx + c = 0$ 的实数解。设判别式 $D = b^2 - 4ac$：
  - $D > 0 \iff$ 与 $x$ 轴**異なる 2 点で交わる**（2 个共有点，$x = \dfrac{-b \pm \sqrt{D}}{2a}$）；
  - $D = 0 \iff$ 与 $x$ 轴**1 点で接する**（1 个共有点即**接点**，$x = -\dfrac{b}{2a}$）；
  - $D < 0 \iff$ 与 $x$ 轴**共有点がない**（0 个共有点）。
  > ⚠️ **教材勘误提示**：原教材第 60 页（`page_0061.jpg`）[5.2] 表格中，$D=0$ 列的「$x$ 軸との共有点の個数と $x$ 座標」误印为「**2個**，$x = \dfrac{-b}{2a}$」，应修正为「**1個**，$x = -\dfrac{b}{2a}$」。

- **与直线 $y = mx + n$ 的共有点**：
  消去 $y$ 得 $ax^2 + (b - m)x + (c - n) = 0$，记其判别式为 $D$。本质是将放物线 $y = f(x)$ 与直线 $y = g(x)$ 的位置关系，转化为新二次函数 $y = F(x) = f(x) - g(x)$ 与 $x$ 轴的位置关系：
  - $D > 0 \iff$ 異なる 2 点で交わる（2 個）
  - $D = 0 \iff$ 1 点で接する（1 個，此时称**接点**）
  - $D < 0 \iff$ 共有点を持たない（0 個）
  - 特别地：**$D \ge 0 \iff$ 共有点をもつ（有公共点）**。

- **二次方程实根分布（解の配置）三要素**：
  当判断 $f(x) = ax^2 + bx + c = 0\;(a > 0)$ 的实根所在区间时，必须联合检查三大要素：
  1. **判别式 $D$**（保证实根存在性及个数）；
  2. **对称轴（軸）位置**（保证两根中心落在区间内）；
  3. **区间端点函数值（境界での値）**（如 $f(p), f(q)$ 的正负）。

### 1.2 一元二次不等式与恒成立条件（二次不等式・定符号）

- **标准解法（$a > 0$）**：若 $a < 0$，先两边同乘 $-1$ 并**反转不等号**化为 $a > 0$。设 $D = b^2 - 4ac$：

| 判别式 $D$ | $ax^2+bx+c=0$ 实数解 | $ax^2+bx+c > 0$ 的解 | $ax^2+bx+c \ge 0$ 的解 | $ax^2+bx+c < 0$ 的解 | $ax^2+bx+c \le 0$ 的解 |
| :---: | :---: | :---: | :---: | :---: | :---: |
| **$D > 0$** | $x = \alpha, \beta\;(\alpha < \beta)$ | $x < \alpha,\;\beta < x$ | $x \le \alpha,\;\beta \le x$ | $\alpha < x < \beta$ | $\alpha \le x \le \beta$ |
| **$D = 0$** | 重解 $x = \alpha$ | $\alpha$ 以外すべての実数 | すべての実数 | 解はない | **$x = \alpha$** |
| **$D < 0$** | 実数解はない | すべての実数 | すべての実数 | 解はない | 解はない |

> ⚠️ **教材勘误提示**：
> 1. 原教材第 64 页（`page_0065.jpg`）[6.1] ③ 中，将 $a>0, D=0$ 时 `$ax^2+bx+c \le 0$ の解` 误印为「ない」，正确应为 **$x = \alpha$**（第 66 页总结表正确）。
> 2. 原教材第 65 页（`page_0066.jpg`）[6.1] ④ 中，将 `$(x-\alpha)^2 \le 0$ の解` 误印为「ない」，正确应为 **$x = \alpha$**。
> 3. 原教材第 65 页（`page_0066.jpg`）[6.1] ⑥ 中，左下角与右下角均误印了不等号方向：
>    - 原误印：`常に ax^2+bx+c > 0 ⇔ a<0, D<0` → 应修正为 **`常に ax^2+bx+c < 0 ⇔ a<0, D<0`**；
>    - 原误印：`常に ax^2+bx+c ≥ 0 ⇔ a<0, D≤0` → 应修正为 **`常に ax^2+bx+c ≤ 0 ⇔ a<0, D≤0`**。

- **二次式的定符号（絶対不等式）**（$a \neq 0$）：
  - 常に $ax^2 + bx + c > 0 \iff a > 0 \text{ かつ } D < 0$
  - 常に $ax^2 + bx + c \ge 0 \iff a > 0 \text{ かつ } D \le 0$
  - 常に $ax^2 + bx + c < 0 \iff a < 0 \text{ かつ } D < 0$
  - 常に $ax^2 + bx + c \le 0 \iff a < 0 \text{ かつ } D \le 0$

### 1.3 指数的扩张与累乘根（指数の拡張・累乗根）

- **0 与负整数指数**（$a \neq 0$，$n$ 为正整数）：$a^0 = 1,\qquad a^{-n} = \dfrac{1}{a^n}$。
- **累乘根（$a$ の $n$ 乗根）**：$n$ 次方等于 $a$ 的数。记号 $\sqrt[n]{a}$ 定义为：
  - $a > 0$ 时：$a$ 的实数 $n$ 次方根中**正的那个**（$\sqrt[n]{a} > 0$）；
  - $a = 0$ 时：$\sqrt[n]{0} = 0$；
  - $a < 0$ 时：仅当 $n$ 为**奇数**时存在实数 $n$ 次方根，且 $\sqrt[n]{a} < 0$。
- **累乘根的性质**（$a > 0, b > 0$，$m, n, p$ 为正整数）：
  $$\sqrt[n]{a}\sqrt[n]{b} = \sqrt[n]{ab}, \quad \frac{\sqrt[n]{a}}{\sqrt[n]{b}} = \sqrt[n]{\frac{a}{b}}, \quad (\sqrt[n]{a})^m = \sqrt[n]{a^m}, \quad \sqrt[m]{\sqrt[n]{a}} = \sqrt[mn]{a}, \quad \sqrt[n]{a^m} = \sqrt[np]{a^{mp}}$$
  > ⚠️ **教材勘误提示**：原教材第 72 页（`page_0073.jpg`）[1.4] 下半部分左侧将 $\sqrt[m]{\sqrt[n]{a}} = \sqrt[mn]{a}$ 误印为 $\sqrt[m]{\sqrt[n]{a}} = \sqrt[mn]{ab}$（多印了字母 $b$），务必修正。
- **有理数指数**（$a > 0$，$m, n$ 为正整数，$r$ 为正有理数）：
  $$a^{\frac{m}{n}} = \sqrt[n]{a^m}, \qquad a^{-r} = \frac{1}{a^r}$$
- **有理数指数法则**（$a > 0, b > 0$，$r, s$ 为有理数）：
  $$a^r a^s = a^{r+s}, \quad \frac{a^r}{a^s} = a^{r-s}, \quad (a^r)^s = a^{rs}, \quad (ab)^r = a^r b^r, \quad \left(\frac{a}{b}\right)^r = \frac{a^r}{b^r}$$

### 1.4 指数函数及其图像与性质（指数関数）

- **定义**：$y = a^x\;(a > 0,\; a \neq 1)$，称 $a$ 为**底（てい）**。
- **基本性质**：
  - 定义域为**实数全体（実数全体）**，值域为**正数全体（正の数全体，$y > 0$）**。
  > ⚠️ **教材勘误提示**：原教材第 73 页（`page_0074.jpg`）[2.2] ① 将「値域」误印为同音错别字「地域」，应修正为「**値域（ちいき）**」。
  - 恒过定点 **$(0, 1)$** 与 **$(1, a)$**，以 **$x$ 轴为渐近线（漸近線）**。
  - $y = a^x$ 与 $y = \left(\dfrac{1}{a}\right)^x = a^{-x}$ 关于 **$y$ 轴对称**。
  - **单调性**：
    - $a > 1$ 时（右上がり・单调递增）：$p < q \iff a^p < a^q$；
    - $0 < a < 1$ 时（右下がり・单调递减）：$p < q \iff a^p > a^q$。

### 1.5 国内高中 vs. 日本 EJU 考纲差异与符号习惯

| 对比维度 | 国内高中习惯 | 日本 EJU 习惯 | 备课/应试提醒 |
| :--- | :--- | :--- | :--- |
| **抛物线凹凸性** | 称「开口向上 / 开口向下」 | 称 **下に凸（向下凸） / 上に凸（向上凸）** | 极易说反！$a>0$ 是「下に凸」，$a<0$ 是「上に凸」 |
| **不等式解的写法** | 常用集合或区间 $(-\infty,\alpha)\cup(\beta,+\infty)$ | 严格用不等式并列 **$x < \alpha,\;\beta < x$** | EJU 填空框全部用不等号形式，不用区间符号 |

| **绝对值与方程根数** | 常代数分段硬算 | 强烈推崇 **图像平移法**（$y = |f(x)|$ 与 $y = mx+k$） | 如演習問題 5-(10)，画图+临界切线法秒杀 |

### 第三章 演習問題 3-(10)

- **【原题重现与翻译】**
  - 原题：$x$ の方程式 $(i+1)x^2 + (k+i)x + ki + 1 = 0$ が実数解を持つとき、実数 $k$ の値を求めよ。ただし、$i^2 = -1$
  - 中文：当关于 $x$ 的方程 $(i+1)x^2 + (k+i)x + ki + 1 = 0$ 有实数解时，求实数 $k$ 的值。其中 $i^2 = -1$。
- **【考点定位】**
  - 复数相等的充要条件（实部、虚部分别为 $0$）+ 含虚数系数的二次方程有实数解的求法。
- **【分步标准解答】**
  実数解を $x$（$x$ は実数）とすると、与えられた方程式を $i$ について整理して：
  $$(x^2 + kx + 1) + (x^2 + x + k)i = 0$$
  > 💡 讲师批注：**最高频易错点！** 看到「実数解を持つ」切忌直接对复数系数方程使用判别式 $D \ge 0$！判别式 $D \ge 0$ **仅适用于实系数二次方程**。遇到虚数系数方程有实数解，必须用「**复数相等条件**：把实数解 $x$ 代入，分离实部与虚部」。

  $x, k$ はともに実数であるから、$x^2 + kx + 1$ と $x^2 + x + k$ も実数である。
  したがって、複素数の相等条件により：
  $$\begin{cases} x^2 + kx + 1 = 0 & \cdots ① \\ x^2 + x + k = 0 & \cdots ② \end{cases}$$
  > 💡 讲师批注：务必写明「$x, k$ は実数であるから、$x^2+kx+1,\; x^2+x+k$ は実数」，这是日本记述式解答的得分点。

  $① - ②$ より $x^2$ を消去すると：
  $$(k - 1)x + (1 - k) = 0$$
  $$(k - 1)(x - 1) = 0$$
  ゆえに、$k = 1$ または $x = 1$。
  > 💡 讲师批注：不要草率地两边直接除以 $(k-1)$！必须因式分解后分类讨论 $k=1$ 与 $x=1$ 两种情况。

  - **（ア）$k = 1$ のとき**：
    ① に代入すると $x^2 + x + 1 = 0$。
    この 2 次方程式の判別式は $D = 1^2 - 4 \cdot 1 \cdot 1 = -3 < 0$ となり、実数解 $x$ を持たない（不適）。
    > 💡 讲师批注：这是经典的「伪解陷阱」！当 $k=1$ 时方程化为 $(1+i)(x^2+x+1)=0$，只有虚数解而没有实数解，必须舍去！

  - **（イ）$x = 1$ のとき**：
    ① に代入すると $1^2 + k \cdot 1 + 1 = 0 \implies k = -2$。

    > 💡 讲师批注：验算 $k=-2, x=1$ 代入原方程：$(i+1) + (-2+i) + (-2i+1) = (1-2+1) + (1+1-2)i = 0$，100% 成立！
- **【最终答案】**
  **$k = -2$**

### 演習問題 4-(1)

- **【原题重现与翻译】**
  - 原题：放物線 $y = x^2 - 4x + k$ と $x$ 軸の共有点の個数は、定数 $k$ の値によってどのように変わるか。
  - 中文：抛物线 $y = x^2 - 4x + k$ 与 $x$ 轴的共有点个数随常数 $k$ 的值如何变化？
- **【考点定位】**
  - 二次函数图像与 $x$ 轴共有点个数与判别式 $D/4$ 的对应关系。
- **【分步标准解答】**
  2 次方程式 $x^2 - 4x + k = 0$ の判別式を $D$ とすると：
  $$\frac{D}{4} = (-2)^2 - 1 \cdot k = 4 - k$$
  > 💡 讲师批注：一次项系数为偶数 $-4$，使用 $\dfrac{D}{4} = (-2)^2 - k$ 最简洁。也可以用配方法 $y = (x-2)^2 + (k-4)$，从顶点纵坐标 $k-4$ 的正负直接判断，结果完全等价。

  - $\dfrac{D}{4} > 0$ すなわち $4 - k > 0 \iff k < 4$ のとき、共有点は **2 個**。
  - $\dfrac{D}{4} = 0$ すなわち $4 - k = 0 \iff k = 4$ のとき、共有点は **1 個**。
  - $\dfrac{D}{4} < 0$ すなわち $4 - k < 0 \iff k > 4$ のとき、共有点は **0 個**。
  > 💡 讲师批注：注意移项变号：$4 - k > 0 \iff k < 4$，不要粗心写成 $k > 4$。
- **【最终答案】**
  **$k < 4$ のとき 2 個、$k = 4$ のとき 1 個、$k > 4$ のとき 0 個**

### 演習問題 4-(2)

- **【原题重现与翻译】**
  - 原题：放物線 $y = x^2 + 3x + a$ が直線 $y = x + 4$ と共有点をもつように、定数 $a$ の値の範囲を定めよ。
  - 中文：确定常数 $a$ 的取值范围，使抛物线 $y = x^2 + 3x + a$ 与直线 $y = x + 4$ 有共有点。
- **【考点定位】**
  - 抛物线与直线有共有点 $\iff D \ge 0$。
- **【分步标准解答】**
  2 式から $y$ を消去すると：
  $$x^2 + 3x + a = x + 4$$
  $$x^2 + 2x + a - 4 = 0 \quad \cdots ①$$
  放物線と直線が共有点をもつための条件は、2 次方程式 ① が実数解をもつこと、すなわち ① の判別式 $D$ が $D \ge 0$ となることである。
  > 💡 讲师批注：「共有点をもつ」包含「2 个交点（$D>0$）」和「1 个切点（$D=0$）」，所以必须带等号 **$D \ge 0$**！

  $$\frac{D}{4} = 1^2 - 1 \cdot (a - 4) = 5 - a$$
  $\dfrac{D}{4} \ge 0$ より：
  $$5 - a \ge 0 \implies a \le 5$$
  > 💡 讲师批注：常数项是整体 $(a-4)$，代入 $-ac$ 时务必加括号：$-(a-4) = -a + 4$。验算临界值 $a=5$：$x^2+2x+1=(x+1)^2=0$，恰在 $x=-1$ 处相切，正确！
- **【最终答案】**
  **$a \le 5$**

### 演習問題 4-(3)

- **【原题重现与翻译】**
  - 原题：放物線 $y = -x^2$ のグラフと直線 $y = -2x + k$ の共有点の個数を調べよ。ただし、$k$ は定数とする。
  - 中文：讨论抛物线 $y = -x^2$ 的图像与直线 $y = -2x + k$ 的共有点个数。其中 $k$ 为常数。
- **【考点定位】**
  - 开口向下（上に凸）的抛物线与直线的共有点个数讨论。
- **【分步标准解答】**
  2 式から $y$ を消去すると：
  $$-x^2 = -2x + k$$
  移項して整理すると：
  $$x^2 - 2x + k = 0 \quad \cdots ①$$
  > 💡 讲师批注：移项把二次项系数整理为正数 $+1$，可有效避免判别式正负号出错。

  ① の判別式を $D$ とすると：
  $$\frac{D}{4} = (-1)^2 - 1 \cdot k = 1 - k$$
  - $\dfrac{D}{4} > 0 \iff 1 - k > 0 \iff k < 1$ のとき、共有点は **2 個**。
  - $\dfrac{D}{4} = 0 \iff 1 - k = 0 \iff k = 1$ のとき、共有点は **1 個**。
  - $\dfrac{D}{4} < 0 \iff 1 - k < 0 \iff k > 1$ のとき、共有点は **0 個**。
  > 💡 讲师批注：几何直观验证：直线斜率为 $-2$，$y = -x^2$ 开口向下，当直线向上平移（$k$ 增大）超过切线 $y = -2x + 1$（切点 $(1, -1)$）后，与抛物线脱离无交点，符合 $k > 1$ 时 0 個。
- **【最终答案】**
  **$k < 1$ のとき 2 個、$k = 1$ のとき 1 個、$k > 1$ のとき 0 個**

  $$\frac{D}{4} = (-a)^2 - 1 \cdot (-3a) = a^2 + 3a = a(a + 3)$$

  - **[2] 1 つの解が正、もう 1 つの解が負となる条件**：

    $$f(0) < 0$$

    $$-3a < 0 \implies a > 0$$

### 演習問題 4-(5)

- **【原题重现与翻译】**
  - 原题：$x$ についての 2 次方程式 $3x^2 - 2(m+1)x + m^2 = 0$ が $1$ より大きく、$2$ より小さい異なる 2 つの実数解を持つとき、定数 $m$ の範囲を求めよ。
  - 中文：当关于 $x$ 的二次方程 $3x^2 - 2(m+1)x + m^2 = 0$ 有两个大于 $1$ 且小于 $2$ 的不同实数解时，求常数 $m$ 的取值范围。
- **【考点定位】**
  - 二次方程两根在开区间 $(1, 2)$ 内的充要条件（判别式 + 对称轴 + 端点函数值）。
- **【分步标准解答】**
  $f(x) = 3x^2 - 2(m+1)x + m^2$ とおくと、$y = f(x)$ は下に凸の放物線であり、軸の方程式は：
  $$x = \frac{2(m+1)}{2 \cdot 3} = \frac{m+1}{3}$$
  $1 < x < 2$ の範囲に異なる 2 つの実数解を持つための必要十分条件は、次の 4 条件を同時に満たすことである：

  1. **判別式 $\dfrac{D}{4} > 0$**：
     $$\frac{D}{4} = \{-(m+1)\}^2 - 3m^2 = (m^2 + 2m + 1) - 3m^2 = -2m^2 + 2m + 1 > 0$$
     $$2m^2 - 2m - 1 < 0$$
     $2m^2 - 2m - 1 = 0$ の解は $m = \dfrac{2 \pm \sqrt{4 + 8}}{4} = \dfrac{1 \pm \sqrt{3}}{2}$ より：
     $$\frac{1 - \sqrt{3}}{2} < m < \frac{1 + \sqrt{3}}{2} \quad \cdots ①$$
     > 💡 讲师批注：估算右端点：$\sqrt{3} \approx 1.732 \implies \dfrac{1 + \sqrt{3}}{2} \approx 1.366$。

  2. **軸の位置 $1 < \dfrac{m+1}{3} < 2$**：
     $$3 < m + 1 < 6 \implies 2 < m < 5 \quad \cdots ②$$

  3. **境界値 $f(1) > 0$**：
     $$f(1) = 3 - 2(m+1) + m^2 = m^2 - 2m + 1 = (m - 1)^2 > 0 \implies m \neq 1 \quad \cdots ③$$

  4. **境界値 $f(2) > 0$**：
     $$f(2) = 12 - 4(m+1) + m^2 = m^2 - 4m + 8 = (m - 2)^2 + 4 > 0 \quad \text{（すべての実数 $m$ で成立）} \quad \cdots ④$$

  ここで ① と ② の共通範囲を調べる。
  $\sqrt{3} < 2 < 3$ より $\dfrac{1 + \sqrt{3}}{2} < \dfrac{1 + 3}{2} = 2$ であるから、①（$m < \dfrac{1+\sqrt{3}}{2}$）と ②（$m > 2$）には**共通範囲が存在しない**。
  > 💡 讲师批注：严谨的数学验证：当 $m > 2$ 时，$3m^2 - (m+1)^2 = 2m^2 - 2m - 1 = 2(m - \frac{1}{2})^2 - \frac{3}{2} > 2(1.5)^2 - 1.5 = 3 > 0$，即判别式必小于 $0$，方程根本无实数解！因此按原题所给方程，严格结论为「条件を満たす定数 $m$ は存在しない（解なし）」。
  > ⚠️ **教材备课提示**：本题在日系参考书中常见原题为 $x^2 - 2(m+1)x + m^2 = 0$ 或 $3x^2 - 2(m+1)x + m = 0$（后者 $D/4 = m^2 - m + 1 > 0$ 恒成立，解得 $2 < m < 5$），原教材可能将常数项 $m$ 误印为 $m^2$。授课时务必向学生演示标准四步法，并强调「若交集为空集，则如实作答『存在しない』」。
- **【最终答案】**
  **条件を満たす定数 $m$ の値は存在しない（解なし）**

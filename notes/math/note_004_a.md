## 一、国内高中基础知识点唤醒与 EJU 考纲差异对比

本切片（P46–P60 完整内容）横跨 **数学 A（整数の性質・記数法）** 与 **数学Ⅰ（二次関数・二次方程式）** 两大核心模块，并衔接 **数学Ⅱ（複素数と方程式・虚数解・解と係数の関係）**。

### 1.1 $n$ 进法（記数法）的四则运算与小数互化（P46–P47）

- **$n$ 进制展开式**：
  - 整数部分：$a_k a_{k-1} \cdots a_1 a_0{}_{(n)} = a_k n^k + a_{k-1} n^{k-1} + \cdots + a_1 n + a_0$（其中首位 $a_k \neq 0$，各位满足 $0 \leqq a_i \leqq n - 1$）。
  - 小数部分：$0.b_1 b_2 b_3 \cdots{}_{(n)} = \dfrac{b_1}{n} + \dfrac{b_2}{n^2} + \dfrac{b_3}{n^3} + \cdots$。
- **$n$ 进制直接竖式运算规则**：
  - **加法**：满 $n$ 进 $1$（$n$ になったら 1 繰り上がる）。
  - **减法**：不够减时向高位借 $1$ 当 $n$（1 借りて $n$ とする）。
  - **除法**：与十进制长除法完全一致，注意每步减法按 $n$ 进制借位；在 2 进制中商的每一位非 $0$ 即 $1$，最为简便。
- **$n$ 进制循环小数与 10 进制分数互化**：
  - **$n$ 进制循环小数 $\to$ 10 进制分数**：设 $x$ 后乘以 $n^k$（$k$ 为循环节长度）错位相减。
  - **10 进制分数 $\to$ $n$ 进制小数**：反复「**乘基数 $n$ 取整数部分**」，余下的真分数继续乘 $n$，直到余数为 $0$ 或出现重复真分数（进入循环）。

### 1.2 函数定义与一次函数图像（P48）

- **函数（関数）**：变量 $x$ 每取定一个值，变量 $y$ 都有唯一确定的值与之对应，记作 $y = f(x)$。
- **定义域（定義域）**与**值域（値域）**：分别指 $x$ 的取值范围（変域）与对应的 $y = f(x)$ 的取值范围。
- **一次函数 $y = ax + b$**：
  - $a \neq 0$：斜率（傾き）为 $a$，$y$ 截距（$y$ 切片）为 $b$；$a > 0$ 右上升，$a < 0$ 右下降。
  - $a = 0$：$y = b$ 为平行于 $x$ 轴（垂直于 $y$ 轴）的水平直线。

### 1.3 二次函数的图像、配方与几何变换（P49–P52）

- **三种解析式形式**：
  1. **一般形（一般形）**：$y = ax^2 + bx + c \ (a \neq 0)$ —— 已知 3 点坐标时首选。
  2. **基本形（基本形 / 顶点式）**：$y = a(x - p)^2 + q$ —— 已知顶点、对称轴或最值时首选。
  3. **分解形（分解形 / 交点式）**：$y = a(x - \alpha)(x - \beta)$ —— 已知与 $x$ 轴两交点时首选。
- **配方公式（平方完成）**：
  $$y = ax^2 + bx + c = a\left(x + \frac{b}{2a}\right)^2 - \frac{b^2 - 4ac}{4a}$$
  - **对称轴（軸）**：直線 $x = -\dfrac{b}{2a}$；**顶点（頂点）**：$\left(-\dfrac{b}{2a},\; -\dfrac{b^2 - 4ac}{4a}\right)$。
  - **开口方向**：$a > 0$ 为**下に凸（开口向上）**；$a < 0$ 为**上に凸（开口向下）**。
- **平移与对称变换（核心易错点：点变换 vs. 曲线方程变换）**：

| 变换类型 | 点的坐标变换 $(a, b) \to$ | 曲线方程变换 $y = f(x) \to$ | 记忆口诀 |
| :--- | :--- | :--- | :--- |
| $x$ 轴方向 $+p$，$y$ 轴方向 $+q$ 平行移动 | $(a + p,\; b + q)$ | $y - q = f(x - p)$ | **点加方程减**（$x \to x-p,\; y \to y-q$） |
| 关于 $x$ 轴对称（$x$ 軸対称） | $(a,\; -b)$ | $-y = f(x)$ | $y$ 变号（$y \to -y$） |
| 关于 $y$ 轴对称（$y$ 軸対称） | $(-a,\; b)$ | $y = f(-x)$ | $x$ 变号（$x \to -x$） |
| 关于原点对称（原点対称） | $(-a,\; -b)$ | $-y = f(-x)$ | $x, y$ 同时变号 |

### 1.4 二次函数的最大・最小与分类讨论（P53–P56）

- **无定义域限制（実数全体）**：
  - $a > 0$（下に凸）：$x = p$ 处取最小値 $q$，无最大値。
  - $a < 0$（上に凸）：$x = p$ 处取最大値 $q$，无最小値。
  > ⚠️ **教材勘误提示**：原教材第 52 页（`page_0053.jpg`）`[3.1]` 中第二行误印为「$a > 0$ のとき $x = p$ で最大値 $q$」，应修正为「**$a < 0$ のとき** $x = p$ で最大値 $q$」。
- **闭区间 $h \leqq x \leqq k$ 上的最值（EJU 压轴高频核心！）**：
  - 设 $a > 0$（下に凸），对称轴 $x = p$，区间中点 $m = \dfrac{h + k}{2}$：
    - **最小値看「轴与区间」**（分 3 类）：$p < h$（左外，取 $f(h)$）、$h \leqq p \leqq k$（区间内，取顶点 $f(p)$）、$p > k$（右外，取 $f(k)$）。
    - **最大値看「轴与中点」**（分 3 类）：$p < m$（轴偏左，取右端 $f(k)$）、$p = m$（轴居中，两端同取 $f(h)=f(k)$）、$p > m$（轴偏右，取左端 $f(h)$）。
  - 若 $a < 0$（上に凸），最大値与最小値的判定逻辑完全对调。
  - 若区间为**开区间或半开半闭区间**（如 $h < x \leqq k$），端点无法取到时可能「最大値（最小値）はない」。

### 1.5 二次方程、判别式与韦达定理（P56–P60）

- **求根公式（解の公式）**（$ax^2 + bx + c = 0,\; a \neq 0$）：
  - 一般形式：$x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$
  - 一次项为偶数 $b = 2b'$ 时（**日本考场必备提速公式**）：$x = \dfrac{-b' \pm \sqrt{b'^2 - ac}}{a}$
- **判别式（判別式）** $D = b^2 - 4ac$（或 $\dfrac{D}{4} = b'^2 - ac$）：
  - $D > 0 \iff$ 異なる 2 つの実数解（2 个不同实数解）
  - $D = 0 \iff$ ただ 1 つの実数解・重解（1 个重根）
  - $D < 0 \iff$ 異なる 2 つの虚数解（2 个共轭虚数解，実数解は 0 個）
- **根与系数的关系（解と係数の関係 / 韦达定理）**：
  $$\alpha + \beta = -\frac{b}{a}, \qquad \alpha\beta = \frac{c}{a}, \qquad ax^2 + bx + c = a(x - \alpha)(x - \beta)$$

| 对比维度 | 国内高中习惯 | 日本 EJU 习惯 | 备课/应试提醒 |
| :--- | :--- | :--- | :--- |

#### 演習問題 4-(6)-[2]
- **【原题重现与翻译】**
  - 原题：$[2]\ 3420_{(5)} - 2434_{(5)}\ [5\text{進法}]$
  - 中文：计算 $3420_{(5)} - 2434_{(5)}$（用 5 进制表示）。
  > ⚠️ **教材勘误提示**：原教材第 45 页（`page_0046.jpg`）将减数误印为 $2434_{(2)}$，但 2 进制数字只能包含 $0$ 和 $1$，绝不可能出现 $2, 3, 4$。结合右侧标注「$[5\text{進法}]$」，原题应为 **$3420_{(5)} - 2434_{(5)}$**。以下按修正后的正确题目解答。
- **【考点定位】**
  - 5 进制直接减法（借 1 当 5）。
- **【分步标准解答】**
  5 進法の筆算で、引けないときは $1$ つ上の位から $1$ 借りて $5$ として計算する。
  - $5^0$ の位：$0 - 4$ は引けないので $5^1$ の位から $1$ 借りる $\implies 5 - 4 = 1$
  - $5^1$ の位：$(2 - 1) - 3 = 1 - 3$ は引けないので $5^2$ の位から $1$ 借りる $\implies (1 + 5) - 3 = 3$
  - $5^2$ の位：$(4 - 1) - 4 = 3 - 4$ は引けないので $5^3$ の位から $1$ 借りる $\implies (3 + 5) - 4 = 4$
  - $5^3$ の位：$(3 - 1) - 2 = 0$
  $$3420_{(5)} - 2434_{(5)} = 431_{(5)}$$
  > 💡 讲师批注：十进制验算：$3420_{(5)} = 3\cdot125 + 4\cdot25 + 2\cdot5 = 485$，$2434_{(5)} = 2\cdot125 + 4\cdot25 + 3\cdot5 + 4 = 369$，$485 - 369 = 116 = 4\cdot25 + 3\cdot5 + 1 = 431_{(5)}$。反向加法验算：$2434_{(5)} + 431_{(5)} = 3420_{(5)}$，无误！
- **【最终答案】**
  **$431_{(5)}$**

#### 演習問題 4-(6)-[3]
- **【原题重现与翻译】**
  - 原题：$[3]\ 413_{(5)} + 32_{(5)}\ [5\text{進法}]$
  - 中文：计算 $413_{(5)} + 32_{(5)}$（用 5 进制表示）。
- **【考点定位】**
  - 5 进制连环进位加法（逢 5 进 1）。
- **【分步标准解答】**
  下の位から順に足し、$5$ になったら $1$ 繰り上げる。
  - $5^0$ の位：$3 + 2 = 5 = 10_{(5)}$（$0$ を書き、$1$ 繰り上げ）

#### 演習問題 4-(7)
- **【原题重现与翻译】**
  - 原题：自然数 $N$ を 6 進法と 9 進法で表すと、それぞれ 3 桁の数 $abc_{(6)}$ と $cab_{(9)}$ になるという。$a, b, c$ の値を求めよ。また、$N$ を 10 進法で表せ。
  - 中文：将自然数 $N$ 分别用 6 进制和 9 进制表示，得到两个三位数 $abc_{(6)}$ 和 $cab_{(9)}$。求 $a, b, c$ 的值，并将 $N$ 用 10 进制表示。
- **【考点定位】**
  - 进制展开式 + 整数不定方程 + 各位数字范围限制（最高位非零）。
- **【分步标准解答】**
  $N$ は 6 進法で 3 桁の $abc_{(6)}$、9 進法で 3 桁の $cab_{(9)}$ であるから、$a, b, c$ は整数で、次の範囲を満たす。
  $$1 \leqq a \leqq 5, \qquad 0 \leqq b \leqq 5, \qquad 1 \leqq c \leqq 5$$
  > 💡 讲师批注：极易漏掉 $c \neq 0$ 和 $c \leqq 5$！因为 $c$ 既是 9 进制的首位（$c \geqq 1$），又是 6 进制的个位（$c \leqq 5$），取交集得 $1 \leqq c \leqq 5$。

  $N$ を 10 進法で表すと、
  $$N = 6^2 a + 6b + c = 36a + 6b + c$$
  $$N = 9^2 c + 9a + b = 81c + 9a + b$$
  よって、
  $$36a + 6b + c = 81c + 9a + b$$
  整理すると、
  $$27a + 5b = 80c \iff 27a = 5(16c - b)$$
  > 💡 讲师批注：不定方程缩范围的神技——**利用整除性（倍数の性質）**！右侧是 $5$ 的倍数，而 $27$ 与 $5$ 互质，因此 $a$ 必为 $5$ 的倍数。

  $27$ と $5$ は互いに素であるから、$a$ は $5$ の倍数である。$1 \leqq a \leqq 5$ より、
  $$a = 5$$
  これを $27a + 5b = 80c$ に代入して、
  $$135 + 5b = 80c \implies 27 + b = 16c$$
  ここで $0 \leqq b \leqq 5$ であるから、
  $$27 \leqq 16c \leqq 32$$
  これを満たす整数 $c$ は $c = 2$ のみである。このとき、
  $$b = 16 \cdot 2 - 27 = 5$$
  これは $0 \leqq b \leqq 5$ を満たす。

  したがって、$N$ を 10 進法で表すと、
  $$N = 36 \cdot 5 + 6 \cdot 5 + 2 = 180 + 30 + 2 = 212$$
  > 💡 讲师批注：用 9 进制反向验算：$cab_{(9)} = 255_{(9)} = 2\cdot81 + 5\cdot9 + 5 = 162 + 45 + 5 = 212$，完美一致！
- **【最终答案】**
  **$a = 5,\; b = 5,\; c = 2,\; N = 212$**

#### 演習問題 4-(8)
- **【原题重现与翻译】**
  - 原题：$n$ は $2$ 以上の自然数とする。4 進数 $321_{(4)}$ を $n$ 進法で表すと $111_{(n)}$ となるような $n$ の値を求めよ。

#### 演習問題 4-(9)
- **【原题重现与翻译】**
  - 原题：$0.\dot{1}\dot{2}_{(3)}$ を 10 進法における既約分数で表せ。
  - 中文：将 3 进制循环小数 $0.\dot{1}\dot{2}_{(3)}$ 表示为 10 进制的既约分数。
- **【考点定位】**
  - $n$ 进制循环小数化 10 进制分数（错位相减法 / 无穷等比级数）。
- **【分步标准解答】**
  $x = 0.\dot{1}\dot{2}_{(3)} = 0.121212\cdots_{(3)}$ とおく。

  $$9x = 12.\dot{1}\dot{2}_{(3)}$$
  > 💡 讲师批注：关键提醒！在 $n$ 进制下，小数点右移 $k$ 位等价于乘以 **$n^k$**，切不可惯性写成 $100x$！这里 $n = 3,\; k = 2$，故乘以 $3^2 = 9$。

  辺々を引くと、
  $$9x - x = 12.\dot{1}\dot{2}_{(3)} - 0.\dot{1}\dot{2}_{(3)}$$
  $$8x = 12_{(3)}$$
  ここで $12_{(3)} = 1 \cdot 3 + 2 = 5$ であるから、
  $$8x = 5 \implies x = \frac{5}{8}$$

- **【最终答案】**
  **$\dfrac{5}{8}$**

#### 演習問題 4-(10)
- **【原题重现与翻译】**
  - 原题：$\dfrac{7}{9}$ を 3 進法、8 進法の小数でそれぞれ表せ。
  - 中文：将 $\dfrac{7}{9}$ 分别用 3 进制和 8 进制的小数表示。
- **【考点定位】**
  - 10 进制分数化 $n$ 进制小数（乘基数取整法）。
- **【分步标准解答】**
  1. **3 進法で表す**：
     $$\frac{7}{9} \times 3 = \frac{7}{3} = \mathbf{2} + \frac{1}{3} \quad (\text{小数第 1 位：} 2)$$

     > 💡 讲师批注：本题分母 $9 = 3^2$，直接拆分子更快：$\dfrac{7}{9} = \dfrac{2\cdot3 + 1}{3^2} = \dfrac{2}{3} + \dfrac{1}{3^2} = 0.21_{(3)}$，是有限小数！

  2. **8 進法で表す**：
     $$\frac{7}{9} \times 8 = \frac{56}{9} = \mathbf{6} + \frac{2}{9} \quad (\text{小数第 1 位：} 6)$$
     $$\frac{2}{9} \times 8 = \frac{16}{9} = \mathbf{1} + \frac{7}{9} \quad (\text{小数第 2 位：} 1)$$

     > 💡 讲师批注：反向验算 $x = 0.\dot{6}\dot{1}_{(8)}$：$8^2 x - x = 61_{(8)} \implies 63x = 6\cdot8 + 1 = 49 \implies x = \dfrac{49}{63} = \dfrac{7}{9}$，完全正确！
- **【最终答案】**
  **3 進法：$0.21_{(3)}$、8 進法：$0.\dot{6}\dot{1}_{(8)}$**

#### 演習問題 1-(2)
- **【原题重现与翻译】**
  - 原题：二次関数 $y = x^2 - 8x - 13$ のグラフをどのように平行移動すると、二次関数 $y = x^2 + 4x + 3$ のグラフに重なるか。
  - 中文：将二次函数 $y = x^2 - 8x - 13$ 的图像如何平移，才能与二次函数 $y = x^2 + 4x + 3$ 的图像重合？
- **【考点定位】**
  - 抛物线的平移等价于**顶点的平移**（前提：二次项系数 $a$ 相同）。
- **【分步标准解答】**
  2 つの二次関数をそれぞれ平方完成して、頂点の座標を求める。
  $$y = x^2 - 8x - 13 = (x - 4)^2 - 16 - 13 = (x - 4)^2 - 29$$
  よって、移動前の頂点は $(4, -29)$。
  $$y = x^2 + 4x + 3 = (x + 2)^2 - 4 + 3 = (x + 2)^2 - 1$$
  よって、移動後の頂点は $(-2, -1)$。
  > 💡 讲师批注：两个抛物线二次项系数均为 $1$，形状完全相同，因此只需计算「目标顶点 $-$ 原顶点」即可得到平移量！

  頂点 $(4, -29)$ を $(-2, -1)$ に移す平行移動の移動量は、
  - $x$ 軸方向：$-2 - 4 = -6$
  - $y$ 軸方向：$-1 - (-29) = 28$

  したがって、$x$ 軸方向に $-6$、$y$ 軸方向に $28$ だけ平行移動すればよい。
  > 💡 讲师批注：验算：将 $x \to x + 6,\; y \to y - 28$ 代入原顶点式，得 $(y - 28) = ((x + 6) - 4)^2 - 29 \implies y = (x + 2)^2 - 1$，完全吻合！
- **【最终答案】**
  **$x$ 軸方向に $-6$、$y$ 軸方向に $28$ だけ平行移動する**

#### 演習問題 1-(3)
- **【原题重现与翻译】**
  - 原题：放物線 $y = x^2 + ax + b$ を原点に関して対称移動し、更に $x$ 軸方向に $-1$、$y$ 軸方向に $8$ だけ平行移動すると、放物線 $y = -x^2 + 5x + 11$ が得られるという。この時、定数 $a, b$ の値を求めよ。
  - 中文：将抛物线 $y = x^2 + ax + b$ 先关于原点对称变换，再沿 $x$ 轴方向平移 $-1$、沿 $y$ 轴方向平移 $8$，得到抛物线 $y = -x^2 + 5x + 11$。求常数 $a, b$ 的值。
- **【考点定位】**
  - 曲线的复合变换（原点对称 + 平行移动）；正推法与逆推法。
- **【分步标准解答】**
  **解法 1（正推法：順に変換する）**：
  1. 放物線 $y = x^2 + ax + b$ を**原点に関して対称移動**すると（$x \to -x,\; y \to -y$ とおき換える）、
     $$-y = (-x)^2 + a(-x) + b$$
     $$-y = x^2 - ax + b \implies y = -x^2 + ax - b$$
     > 💡 讲师批注：原点对称时 $x$ 和 $y$ **必须同时变号**，注意 $(-x)^2 = x^2$，乘以 $-1$ 移到右侧后二次项变为 $-x^2$，一次项 $+ax$ 负负得正！

  2. さらに、これを $x$ 軸方向に $-1$、$y$ 軸方向に $8$ だけ**平行移動**すると（$x \to x - (-1) = x + 1$、$y \to y - 8$ とおき換える）、
     $$y - 8 = -(x + 1)^2 + a(x + 1) - b$$
     $$y = -(x^2 + 2x + 1) + ax + a - b + 8$$
     $$y = -x^2 + (a - 2)x + (a - b + 7)$$
  3. これが $y = -x^2 + 5x + 11$ と一致するから、係数を比較して、
     $$\begin{cases} a - 2 = 5 \\ a - b + 7 = 11 \end{cases}$$
     第 1 式より $a = 7$。第 2 式に代入して $7 - b + 7 = 11 \implies b = 3$。

  **解法 2（逆推法：検算用）**：
  $y = -x^2 + 5x + 11$ を逆順に「$x$ 軸方向に $+1$、$y$ 軸方向に $-8$ 平行移動」すると、
  $$y + 8 = -(x - 1)^2 + 5(x - 1) + 11 \implies y = -x^2 + 7x - 3$$
  さらに原点対称移動すると、
  $$-y = -(-x)^2 + 7(-x) - 3 \implies y = x^2 + 7x + 3$$
  係数を比較して $a = 7,\; b = 3$。完全に一致！
- **【最终答案】**
  **$a = 7,\; b = 3$**

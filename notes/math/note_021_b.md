## 一、国内高中基础知识点唤醒与 EJU 考纲差异对比

本部分（P306–P315）衔接日本 **数学Ⅲ（関数の連続性）** 与 **数学Ⅱ・数学Ⅲ（微分法基礎）**，完整构建从「函数连续性」到「导数定义与基本初等函数求导公式」的理论体系。

### 1.1 函数的连续性（関数の連続性）

- **在一点 $x = a$ 处连续的定义**：
  定义域内一点 $a$ 满足极限 $\displaystyle\lim_{x \to a} f(x)$ 存在，且：
  $$\lim_{x \to a} f(x) = f(a)$$
  几何意义：曲线 $y = f(x)$ 在 $x = a$ 处**不断开（繋がっている）**。
- **区间的记号**：
  - 闭区间（閉区間）：$[a, b] = \{x \mid a \le x \le b\}$（含端点）
  - 开区间（開区間）：$(a, b) = \{x \mid a < x < b\}$（不含端点）
  - 半开半闭区间：$[a, b)$、$(a, b]$；无穷区间：$(a, \infty)$、$(-\infty, b]$、$(-\infty, \infty)$。
  - $f(x)$ 在闭区间 $[a, b]$ 上连续 $\iff$ 在开区间 $(a, b)$ 上连续，且 $\displaystyle\lim_{x \to a+0} f(x) = f(a)$、$\displaystyle\lim_{x \to b-0} f(x) = f(b)$。
- **闭区间上连续函数的两大定理**：
  1. **最大值・最小值定理（最大値・最小値の定理）**：在闭区间 $[a, b]$ 上连续的函数，必在该闭区间上取得最大值和最小值。
  2. **介值定理（中間値の定理）**：若 $f(x)$ 在闭区间 $[a, b]$ 上连续且 $f(a) \neq f(b)$，则对 $f(a)$ 与 $f(b)$ 之间的任意实数 $k$，至少存在一个 $c \in (a, b)$ 使得 $f(c) = k$。
     - **零点存在推论（最常考！）**：若 $f(x)$ 在 $[a, b]$ 上连续，且 $f(a)$ 与 $f(b)$ **异号（異符号）**（即 $f(a)f(b) < 0$），则方程 $f(x) = 0$ 在 $a < x < b$ 内至少有一个实数解。
  > ⚠️ **教材勘误提示**：原教材 P305（`page_0306.jpg`）`[4.2]` 连续函数性质 ①②③ 三处均将「閉**区**間（闭区间）」误印为「閉**空**間（闭空间）」，授课时务必以 P306（`page_0307.jpg`）的正确术语「閉区間」为准。

### 1.2 平均变化率、微分系数与导函数（平均変化率・微分係数・導関数）

- **平均变化率（平均変化率）**：$x$ 从 $a$ 变到 $b$ 时，增量 $\Delta x = b - a$，$\Delta y = f(b) - f(a)$，平均变化率为：
  $$\frac{\Delta y}{\Delta x} = \frac{f(b) - f(a)}{b - a} \quad \text{（几何意义：割线 } AB \text{ 的斜率）}$$
- **微分系数（微分係数）**：$x = a$ 处的瞬时变化率（即导数值）：
  $$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h} = \lim_{x \to a} \frac{f(x) - f(a)}{x - a}$$
  - **几何意义**：曲线 $y = f(x)$ 在点 $A(a, f(a))$ 处的**切线斜率（接線の傾き）**。
  - **可微与连续的关系**：
    $$x = a \text{ で微分可能} \implies x = a \text{ で連続} \quad \text{（逆不成立！反例：} y = |x| \text{ 在 } x=0 \text{ 连续但不可微）}$$
  > ⚠️ **教材勘误提示**：原教材 P308（`page_0309.jpg`）`[5.1]` 正文中「$\Delta y$ 表す」漏印助词「と」、「値 $\alpha$ の限りなく近づく」中「の」应为「に」。
- **导函数（導関数）**：
  $$f'(x) = \frac{dy}{dx} = \frac{d}{dx}f(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$
  - 幂函数与常函数：$(x^n)' = n x^{n-1}$（$n$ 为正整数，后续可推广至任意实数），$(c)' = 0$。

### 1.3 导数的运算法则与基本初等函数求导公式（P312–P315）

1. **线性性**：$\{kf(x) \pm lg(x)\}' = kf'(x) \pm lg'(x)$
2. **积的导数（積の導関数）**：$\{f(x)g(x)\}' = f'(x)g(x) + f(x)g'(x)$
3. **商的导数（商の導関数）**：
   $$\left\{\frac{f(x)}{g(x)}\right\}' = \frac{f'(x)g(x) - f(x)g'(x)}{\{g(x)\}^2}, \qquad \left\{\frac{1}{g(x)}\right\}' = -\frac{g'(x)}{\{g(x)\}^2}$$
4. **复合函数求导法则（合成関数の微分法 / 链式法则）**：
   $$y = f(u),\; u = g(x) \implies \frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}, \qquad \{f(g(x))\}' = f'(g(x)) g'(x)$$
5. **反函数求导法则（逆関数の微分法）**：
   $$y = f^{-1}(x) \iff x = f(y) \implies \frac{dy}{dx} = \frac{1}{\dfrac{dx}{dy}}$$
   > ⚠️ **教材勘误提示**：原教材 P312（`page_0313.jpg`）`[6.5]` 逆関数の微分法公式误印为 $\dfrac{dy}{dx} = \dfrac{1}{\frac{dx}{dy}} = \dfrac{dx}{dy}$，末尾多印了错误的「$= \dfrac{dx}{dy}$」（反函数导数应为倒数，而非自身），务必删去！
6. **三角・对数・指数函数的导数（公式速查表）**：
   | 原函数 $f(x)$ | 导函数 $f'(x)$ | 备注 |
   | :--- | :--- | :--- |
   | $\sin x$ | $\cos x$ | 弧度制限定 |
   | $\cos x$ | $-\sin x$ | 注意负号 |
   | $\tan x$ | $\dfrac{1}{\cos^2 x}$ | 日本几乎不用 $\sec^2 x$ |
   | $\log x$ 或 $\log\|x\|$ | $\dfrac{1}{x}$ | $\log$ 默认以 $e$ 为底 |
   | $\log_a x$ 或 $\log_a\|x\|$ | $\dfrac{1}{x \log a}$ | $a > 0,\; a \neq 1$ |
   | $e^x$ | $e^x$ | 求导不变 |
   | $a^x$ | $a^x \log a$ | $a > 0,\; a \neq 1$ |

### 1.4 国内高中 vs. 日本 EJU 考纲差异与符号习惯

| 对比维度 | 国内高中习惯 | 日本 EJU 习惯 | 备课/应试提醒 |
| :--- | :--- | :--- | :--- |

### 2.2 核心公式的日本课堂口语读法

1. **微分系数符号** $f'(a)$ 与莱布尼茨记号 $\dfrac{dy}{dx}$
   - $f'(a)$ 读作：**エフ・ダッシュ・エー**（日本将撇号 `'` 读作 **ダッシュ / dash**，而英语读 prime！）
   - $\dfrac{dy}{dx}$ 读作：**ディーワイ・ディーエックス**（注意此处**从上往下读**，不同于普通分数的从下往上读！）
2. **增量记号** $\Delta x, \Delta y$
   - 课堂读法：**デルタ・エックス**、**デルタ・ワイ**
3. **链式法则** $\dfrac{dy}{dx} = \dfrac{dy}{du} \cdot \dfrac{du}{dx}$
   - 课堂读法：**ディーワイ・ディーエックス イコール ディーワイ・ディーユー かける ディーユー・ディーエックス**
4. **对数求导** $(\log x)' = \dfrac{1}{x}$
   - 课堂读法：**ログ・エックス の ダッシュ イコール エックス ぶんの いち**

- **【分步标准解答】**
  絶対値記号を外すと、
  $$f(x) = \begin{cases} -x^2 & (-1 \le x < 0) \\ x^2 & (0 \le x \le 2) \end{cases}$$
  1. $-1 \le x < 0$ および $0 < x \le 2$ の範囲では、$f(x)$ は整式で表されるため連続である（左端 $x=-1$ では $\displaystyle\lim_{x\to -1+0}f(x) = -1 = f(-1)$、右端 $x=2$ では $\displaystyle\lim_{x\to 2-0}f(x) = 4 = f(2)$）。
  2. 分かれ目である $x = 0$ について調べる：
     $$\lim_{x \to -0} f(x) = \lim_{x \to -0} (-x^2) = 0, \qquad \lim_{x \to +0} f(x) = \lim_{x \to +0} x^2 = 0$$
     また、$f(0) = 0 \cdot |0| = 0$ である。
     よって、$\displaystyle\lim_{x \to 0} f(x) = 0 = f(0)$ が成り立つため、$f(x)$ は $x = 0$ でも連続である。
  > 💡 讲师批注：分段函数判断连续性的标准流程：① 各分段内部由初等函数性质直接说明连续；② **重点检验分段点**的左极限、右极限与函数值三者是否相等。

  以上より、$f(x)$ は閉区間 $[-1, 2]$ で連続である。
- **【最终答案】**
  **区間 $[-1, 2]$（$-1 \le x \le 2$ のすべての $x$）で連続である。**

#### 演習問題 4-(1)-[2]
- **【原题重现与翻译】**
  - 原题：$-1 \le x \le 2$ とする。次の関数の連続性について調べよ。`[2]` $g(x) = \dfrac{1}{(x-1)^2}\ (x \neq 1),\; g(1) = 0$
  - 中文：设 $-1 \le x \le 2$，讨论函数 $g(x) = \dfrac{1}{(x-1)^2}\ (x \neq 1),\; g(1) = 0$ 的连续性。
- **【考点定位】**
  - 分式函数在分母零点处的发散与不连续性判定。
- **【分步标准解答】**
  1. $x \neq 1$ のとき、$g(x) = \dfrac{1}{(x-1)^2}$ は分母が $0$ でない分数関数であるから、区間 $[-1, 1)$ および $(1, 2]$ で連続である。
  2. $x = 1$ のとき：
     $$\lim_{x \to 1} g(x) = \lim_{x \to 1} \frac{1}{(x-1)^2} = \infty$$
     したがって、$x \to 1$ のとき $g(x)$ の極限値は存在しない（もちろん $g(1) = 0$ とも一致しない）。
     よって、$g(x)$ は $x = 1$ で不連続である。
  > 💡 讲师批注：注意即便题目人为补定义了 $g(1)=0$，由于 $\displaystyle\lim_{x\to 1}g(x) = \infty$（极限值不存在），函数在 $x=1$ 依然不连续（无穷间断点）。
- **【最终答案】**
  **$x = 1$ で不連続であり、$x = 1$ 以外の $[-1, 2]$ の範囲（区間 $[-1, 1)$ および $(1, 2]$）で連続である。**

- **【分步标准解答】**
  **(前半) $f(x)$ の式を求める：**
  $x^{2n} = (x^2)^n$ の極限は $|x|$ と $1$ の大小によって異なるため、以下の 4 つの場合に分ける。
  > 💡 讲师批注：EJU 超级经典大题！遇到 $x^{2n}$ 或 $r^n$ 型极限函数，**必须分 $|x|<1$、$|x|>1$、$x=1$、$x=-1$ 四种情况**（本题分子含奇次幂 $x^{2n-1}$，故 $x=1$ 与 $x=-1$ 的值不同，不可合并！）。

  - **[1] $|x| < 1$（すなわち $-1 < x < 1$）のとき：**
    $\displaystyle\lim_{n \to \infty} x^{2n} = 0$、$\displaystyle\lim_{n \to \infty} x^{2n-1} = 0$ であるから、
    $$f(x) = \frac{0 - 0 + ax^2 + bx}{0 + 1} = ax^2 + bx$$

  - **[2] $|x| > 1$（すなわち $x < -1,\; 1 < x$）のとき：**
    分母・分子を $x^{2n}$ で割ると、$\displaystyle\lim_{n \to \infty} \frac{1}{x^{2n}} = 0$ であるから、
    $$f(x) = \lim_{n \to \infty} \frac{1 - \dfrac{1}{x} + \dfrac{ax^2 + bx}{x^{2n}}}{1 + \dfrac{1}{x^{2n}}} = \frac{1 - \dfrac{1}{x} + 0}{1 + 0} = 1 - \frac{1}{x}$$

  - **[3] $x = 1$ のとき：**
    $1^{2n} = 1$、$1^{2n-1} = 1$ であるから、
    $$f(1) = \lim_{n \to \infty} \frac{1 - 1 + a + b}{1 + 1} = \frac{a + b}{2}$$

  - **[4] $x = -1$ のとき：**
    $(-1)^{2n} = 1$、$(-1)^{2n-1} = -1$ であるから、
    $$f(-1) = \lim_{n \to \infty} \frac{1 - (-1) + a(-1)^2 + b(-1)}{1 + 1} = \frac{2 + a - b}{2}$$

  **(後半) $f(x)$ がすべての $x$ で連続となる $a, b$ を求める：**
  $x \neq \pm 1$ では $f(x)$ は整式または分母が $0$ でない分数式であるから連続である。したがって、$f(x)$ がすべての実数 $x$ で連続であるための必要十分条件は、$x = 1$ および $x = -1$ で連続であることである。

  - **$x = 1$ で連続となる条件**：
    $$\lim_{x \to 1-0} f(x) = \lim_{x \to 1-0} (ax^2 + bx) = a + b$$
    $$\lim_{x \to 1+0} f(x) = \lim_{x \to 1+0} \left(1 - \frac{1}{x}\right) = 1 - 1 = 0$$
    $$f(1) = \frac{a + b}{2}$$
    これら 3 つが一致するためには、$a + b = 0 = \dfrac{a+b}{2}$、すなわち
    $$a + b = 0 \quad \cdots \text{①}$$

  - **$x = -1$ で連続となる条件**：
    $$\lim_{x \to -1+0} f(x) = \lim_{x \to -1+0} (ax^2 + bx) = a - b$$
    $$\lim_{x \to -1-0} f(x) = \lim_{x \to -1-0} \left(1 - \frac{1}{x}\right) = 1 - (-1) = 2$$
    $$f(-1) = \frac{2 + a - b}{2}$$
    これら 3 つが一致するためには、$a - b = 2 = \dfrac{2+a-b}{2}$、すなわち
    $$a - b = 2 \quad \cdots \text{②}$$
  > 💡 讲师批注：妙处在于 $f(1)$ 恰好是左右极限的算术平均值 $\frac{(a+b)+0}{2}$，$f(-1)$ 也恰好是左右极限的平均值 $\frac{(a-b)+2}{2}$，因此只要左右极限相等，必然自动等于函数值！

  ①、② を連立して解くと、① $+$ ② より $2a = 2 \implies a = 1$、① より $b = -1$。
- **【最终答案】**
  **$f(x) = \begin{cases} ax^2 + bx & (|x| < 1) \\ 1 - \dfrac{1}{x} & (|x| > 1) \\ \dfrac{a+b}{2} & (x = 1) \\ \dfrac{2+a-b}{2} & (x = -1) \end{cases}$、連続となる定数は $a = 1,\; b = -1$**

#### 演習問題 5-(2)-[3]
- **【原题重现与翻译】**
  - 原题：`[3]` $y = \dfrac{x}{2x - 1}$（導関数の定義に従って微分せよ）
  - 中文：按导数定义求 $y = \dfrac{x}{2x - 1}$ 的导数。
- **【考点定位】**
  - 按导数定义求一次分式导数（通分展开约去 $h$）。
- **【分步标准解答】**
  $$y' = \lim_{h \to 0} \frac{\dfrac{x+h}{2(x+h) - 1} - \dfrac{x}{2x - 1}}{h}$$
  $$= \lim_{h \to 0} \frac{(x + h)(2x - 1) - x(2x + 2h - 1)}{h(2x + 2h - 1)(2x - 1)}$$
  分子を展開して整理すると、
  $$(2x^2 - x + 2xh - h) - (2x^2 + 2xh - x) = -h$$
  > 💡 讲师批注：检查分子中 $2x^2, -x, 2xh$ 三组项全部成对抵消，只剩 $-h$，完美约分！

  よって、
  $$y' = \lim_{h \to 0} \frac{-h}{h(2x + 2h - 1)(2x - 1)} = \lim_{h \to 0} \frac{-1}{(2x + 2h - 1)(2x - 1)} = -\frac{1}{(2x - 1)^2}$$
  > 💡 讲师批注：用商的求导法则验算：$\dfrac{1 \cdot (2x-1) - x \cdot 2}{(2x-1)^2} = -\dfrac{1}{(2x-1)^2}$，完全一致！
- **【最终答案】**
  **$y' = -\dfrac{1}{(2x - 1)^2}$**

#### 演習問題 5-(2)-[4]
- **【原题重现与翻译】**
  - 原题：`[4]` $y = \sqrt[3]{x^2}$（導関数の定義に従って微分せよ）
  - 中文：按导数定义求 $y = \sqrt[3]{x^2}$ 的导数。
- **【考点定位】**
  - 按导数定义求三次根式导数（利用**立方差公式** $A^3 - B^3 = (A-B)(A^2 + AB + B^2)$ 有理化分子）。
- **【分步标准解答】**
  $A = \sqrt[3]{(x+h)^2}$、$B = \sqrt[3]{x^2}$ とおくと、$A^3 - B^3 = (x+h)^2 - x^2 = 2xh + h^2$ である。
  公式 $A - B = \dfrac{A^3 - B^3}{A^2 + AB + B^2}$ を用いて分子を有理化すると、
  > 💡 讲师批注：**本题是 `[1]`–`[4]` 中最具技巧性的一道！** 二次根号用平方差有理化，三次根号必须用立方差 $A^3 - B^3 = (A-B)(A^2 + AB + B^2)$ 有理化。

  $$y' = \lim_{h \to 0} \frac{\sqrt[3]{(x+h)^2} - \sqrt[3]{x^2}}{h}$$
  $$= \lim_{h \to 0} \frac{(x+h)^2 - x^2}{h\left\{\sqrt[3]{(x+h)^4} + \sqrt[3]{(x+h)^2 x^2} + \sqrt[3]{x^4}\right\}}$$
  $$= \lim_{h \to 0} \frac{h(2x + h)}{h\left\{\sqrt[3]{(x+h)^4} + \sqrt[3]{(x+h)^2 x^2} + \sqrt[3]{x^4}\right\}}$$
  $h$ で約分して $h \to 0$ とすると（ただし $x \neq 0$）、
  $$= \frac{2x}{\sqrt[3]{x^4} + \sqrt[3]{x^4} + \sqrt[3]{x^4}} = \frac{2x}{3\sqrt[3]{x^4}} = \frac{2x}{3x\sqrt[3]{x}} = \frac{2}{3\sqrt[3]{x}}$$
  > 💡 讲师批注：用分数指数幂求导法则验算：$(x^{\frac{2}{3}})' = \frac{2}{3}x^{-\frac{1}{3}} = \frac{2}{3\sqrt[3]{x}}$，结果无误！注意在 $x=0$ 处导数发散（尖点），不可微。
- **【最终答案】**
  **$y' = \dfrac{2}{3\sqrt[3]{x}}$（ただし $x \neq 0$）**

#### 演習問題 5-(3)
- **【原题重现与翻译】**
  - 原题：等式 $\displaystyle\lim_{x \to 1} \frac{x^2 + ax + b}{x - 1} = 3$ を満たす定数 $a, b$ の値を求めよ。
  - 中文：求满足等式 $\displaystyle\lim_{x \to 1} \frac{x^2 + ax + b}{x - 1} = 3$ 的常数 $a, b$ 的值。
- **【考点定位】**
  - 极限存在确定待定系数（分母趋于 $0$ 且极限有限 $\implies$ 分子必趋于 $0$）。
- **【分步标准解答】**
  $x \to 1$ のとき分母 $x - 1 \to 0$ であり、左辺が有限の極限値 $3$ をもつから、分子も $0$ に収束しなければならない。
  > 💡 讲师批注：这是 EJU 极高频基础题！逻辑链必须是「分母 $\to 0$ 且极限存在 $\implies$ 分子 $\to 0$」（先得必要条件，代入求出 $a, b$ 后即自动满足充分性）。

  よって、
  $$\lim_{x \to 1} (x^2 + ax + b) = 1 + a + b = 0 \implies b = -a - 1$$
  これを分子に代入して因数分解すると、
  $$x^2 + ax + b = x^2 + ax - a - 1 = (x^2 - 1) + a(x - 1) = (x - 1)(x + a + 1)$$
  したがって、
  $$\lim_{x \to 1} \frac{x^2 + ax + b}{x - 1} = \lim_{x \to 1} \frac{(x - 1)(x + a + 1)}{x - 1} = \lim_{x \to 1} (x + a + 1) = a + 2$$
  条件より $a + 2 = 3$ であるから、$a = 1$。
  また、$b = -a - 1 = -1 - 1 = -2$。
  > 💡 讲师批注：用导数定义另解：令 $f(x)=x^2+ax+b$，则由 $f(1)=0$ 得 $1+a+b=0$，且原极限 $= f'(1) = 2(1)+a = 3 \implies a=1,\; b=-2$，一秒验算！
- **【最终答案】**
  **$a = 1,\quad b = -2$**

#### 演習問題 5-(4)
- **【原题重现与翻译】**
  - 原题：$\displaystyle\lim_{h \to 0} \frac{f(a - 3h) - f(a)}{h}$ を $f'(a)$ を用いて表せ。
  - 中文：用 $f'(a)$ 表示 $\displaystyle\lim_{h \to 0} \frac{f(a - 3h) - f(a)}{h}$。
  > ⚠️ **教材勘误提示**：原教材 P312（`page_0313.jpg`）将本题的极限下标误印为 $x \to 1$（即 $\lim_{x \to 1}\frac{f(a-3h)-f(a)}{h}$），结合分子分母中的变量 $h$，正确应为 **$h \to 0$**。
- **【考点定位】**
  - 微分系数定义式 $\displaystyle f'(a) = \lim_{k \to 0}\frac{f(a+k)-f(a)}{k}$ 的配凑变形。
- **【分步标准解答】**
  分母を分子の増分 $-3h$ に合わせるため、$-3$ を掛けて割ると、
  $$\lim_{h \to 0} \frac{f(a - 3h) - f(a)}{h} = \lim_{h \to 0} \left\{\frac{f(a + (-3h)) - f(a)}{-3h} \cdot (-3)\right\}$$
  ここで、$k = -3h$ とおくと、$h \to 0$ のとき $k \to 0$ であるから、
  $$= -3 \lim_{k \to 0} \frac{f(a + k) - f(a)}{k} = -3 f'(a)$$
  > 💡 讲师批注：核心口诀——**「分子增分与分母同步」**，见 $f(a + ph) - f(a)$ 除以 $h$，直接等于 $p f'(a)$；此处 $p = -3$，故得 $-3f'(a)$。
- **【最终答案】**
  **$-3f'(a)$**

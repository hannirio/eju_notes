### 第三章 演習問題 2（二次関数の最大・最小と場合分け）— P54–P56

#### 演習問題 2-(1)-[1]
- **【原题重现与翻译】**
  - 原题：次の関数に最大値、最小値があれば、それを求めよ。$[1]\ y = 3x^2 + 4x - 1$
  - 中文：若下列函数存在最大值或最小值，求其值：$y = 3x^2 + 4x - 1$。
- **【考点定位】**
  - 定义域为全体实数时的二次函数最值（配方法）。
- **【分步标准解答】**
  式を平方完成する。
  $$y = 3x^2 + 4x - 1$$
  $$= 3\left(x^2 + \frac{4}{3}x\right) - 1$$
  $$= 3\left\{\left(x + \frac{2}{3}\right)^2 - \frac{4}{9}\right\} - 1$$
  $$= 3\left(x + \frac{2}{3}\right)^2 - \frac{4}{3} - 1$$
  $$= 3\left(x + \frac{2}{3}\right)^2 - \frac{7}{3}$$
  > 💡 讲师批注：展开验算：$3\left(x^2 + \dfrac{4}{3}x + \dfrac{4}{9}\right) - \dfrac{7}{3} = 3x^2 + 4x + \dfrac{4}{3} - \dfrac{7}{3} = 3x^2 + 4x - 1$，无误！

  定義域は実数全体であり、$x^2$ の係数が $3 > 0$（グラフは下に凸）であるから、
  - $x = -\dfrac{2}{3}$ で最小値 $-\dfrac{7}{3}$ をとる。
  - 最大値はない。
- **【最终答案】**
  **$x = -\dfrac{2}{3}$ で最小値 $-\dfrac{7}{3}$、最大値はない**

- **【分步标准解答】**
  まず $f(x)$ を平方完成する。
  $$f(x) = x^2 - 2ax + 3a = (x - a)^2 - a^2 + 3a$$
  グラフは**下に凸**の放物線で、軸は直線 $x = a$、頂点は $(a,\; -a^2 + 3a)$ である。
  また、定義域 $0 \leqq x \leqq 4$ の両端と中央における値をあらかじめ求めておくと、
  $$f(0) = 3a, \qquad f(4) = 16 - 8a + 3a = 16 - 5a, \qquad f(a) = -a^2 + 3a$$
  定義域の中央は $x = \dfrac{0 + 4}{2} = 2$ である。

  **$[1]$ 最大値**（軸 $x = a$ と定義域の中央 $x = 2$ との位置関係で場合分け）：
  > 💡 讲师批注：口诀「**下凸求最大，看轴偏哪边；离轴越远值越大**」！

  - **$a < 2$ のとき**（軸が中央より左 $\implies x = 4$ の方が軸から遠い）：
    $x = 4$ で最大値 $f(4) = 16 - 5a$。
  - **$a = 2$ のとき**（軸がちょうど中央 $\implies$ 両端が軸から等距離）：
    $x = 0,\; 4$ で最大値 $f(0) = f(4) = 6$。
  - **$a > 2$ のとき**（軸が中央より右 $\implies x = 0$ の方が軸から遠い）：
    $x = 0$ で最大値 $f(0) = 3a$。

  **$[2]$ 最小値**（軸 $x = a$ と定義域 $0 \leqq x \leqq 4$ との位置関係で場合分け）：
  > 💡 讲师批注：口诀「**下凸求最小，看轴在不在区间内**」！

  - **$a < 0$ のとき**（軸が定義域の左外）：
    $x = 0$ で最小値 $f(0) = 3a$。
  - **$0 \leqq a \leqq 4$ のとき**（軸が定義域内）：
    $x = a$ で最小値 $f(a) = -a^2 + 3a$。
  - **$a > 4$ のとき**（軸が定義域の右外）：
    $x = 4$ で最小値 $f(4) = 16 - 5a$。
  > 💡 讲师批注：绝佳验算技巧——**边界连续性检验**！在分界点 $a = 0$ 处：$3a = 0$ 与 $-a^2 + 3a = 0$ 相等；在 $a = 4$ 处：$-a^2 + 3a = -4$ 与 $16 - 5a = -4$ 相等；在 $a = 2$ 处：$16 - 5a = 6$ 与 $3a = 6$ 相等！边界值全部无缝衔接，确保计算零失误！
- **【最终答案】**
  - **$[1]$ 最大値**：
    - $a < 2$ のとき：$x = 4$ で最大値 **$16 - 5a$**
    - $a = 2$ のとき：$x = 0,\; 4$ で最大値 **$6$**
    - $a > 2$ のとき：$x = 0$ で最大値 **$3a$**
  - **$[2]$ 最小値**：
    - $a < 0$ のとき：$x = 0$ で最小値 **$3a$**
    - $0 \leqq a \leqq 4$ のとき：$x = a$ で最小値 **$-a^2 + 3a$**
    - $a > 4$ のとき：$x = 4$ で最小値 **$16 - 5a$**

- **【考点定位】**

- **【分步标准解答】**
  $f(x)$ を平方完成すると、
  $$f(x) = (x - 1)^2 + 1$$
  グラフは**下に凸**の放物線で、軸は直線 $x = 1$、頂点は $(1, 1)$ である。
  区間 $a \leqq x \leqq a + 2$ の中央は $x = \dfrac{a + (a + 2)}{2} = a + 1$ である。
  また、両端と頂点での値を求めておくと、
  $$f(a) = a^2 - 2a + 2$$
  $$f(a + 2) = \{(a + 2) - 1\}^2 + 1 = (a + 1)^2 + 1 = a^2 + 2a + 2$$
  $$f(1) = 1$$
  > 💡 讲师批注：计算 $f(a+2)$ 时，直接代入配方后的基本形 $(x-1)^2 + 1$ 比代入一般形快一倍，且不易算错！

  **$[1]$ 最大値**（区間の中央 $a + 1$ と軸 $1$ の大小関係で場合分け）：
  - $a + 1 < 1$ すなわち **$a < 0$ のとき**（区間が左寄り $\implies$ 左端 $x = a$ が軸から遠い）：
    $x = a$ で最大値 $f(a) = a^2 - 2a + 2$。
  - $a + 1 = 1$ すなわち **$a = 0$ のとき**（区間の中央と軸が一致）：
    $x = 0,\; 2$ で最大値 $f(0) = f(2) = 2$。
  - $a + 1 > 1$ すなわち **$a > 0$ のとき**（区間が右寄り $\implies$ 右端 $x = a + 2$ が軸から遠い）：
    $x = a + 2$ で最大値 $f(a + 2) = a^2 + 2a + 2$。

  **$[2]$ 最小値**（軸 $1$ が区間 $[a,\; a + 2]$ のどこにあるかで場合分け）：
  - $a + 2 < 1$ すなわち **$a < -1$ のとき**（区間が軸より完全に左）：
    $x = a + 2$ で最小値 $f(a + 2) = a^2 + 2a + 2$。
  - $a \leqq 1 \leqq a + 2$ すなわち **$-1 \leqq a \leqq 1$ のとき**（軸が区間内に含まれる）：
    $x = 1$ で最小値 $f(1) = 1$。
  - $1 < a$ すなわち **$a > 1$ のとき**（区間が軸より完全に右）：
    $x = a$ で最小値 $f(a) = a^2 - 2a + 2$。
  > 💡 讲师批注：边界检验：$a = -1$ 时 $a^2 + 2a + 2 = 1 - 2 + 2 = 1 = f(1)$；$a = 1$ 时 $a^2 - 2a + 2 = 1 - 2 + 2 = 1 = f(1)$；$a = 0$ 时两端均为 $2$，全部无缝衔接！
- **【最终答案】**
  - **$[1]$ 最大値**：
    - $a < 0$ のとき：$x = a$ で最大値 **$a^2 - 2a + 2$**
    - $a = 0$ のとき：$x = 0,\; 2$ で最大値 **$2$**
    - $a > 0$ のとき：$x = a + 2$ で最大値 **$a^2 + 2a + 2$**
  - **$[2]$ 最小値**：
    - $a < -1$ のとき：$x = a + 2$ で最小値 **$a^2 + 2a + 2$**
    - $-1 \leqq a \leqq 1$ のとき：$x = 1$ で最小値 **$1$**
    - $a > 1$ のとき：$x = a$ で最小値 **$a^2 - 2a + 2$**

#### 演習問題 2-(4)
- **【原题重现与翻译】**
  - 原题：定義域 $0 \leqq x \leqq 3$ とする関数 $f(x) = ax^2 - 2ax + b$ の最大値が $9$、最小値が $1$ のとき、定数 $a, b$ の値を求めよ。
  - 中文：已知定义域为 $0 \leqq x \leqq 3$ 的函数 $f(x) = ax^2 - 2ax + b$ 的最大值为 $9$、最小值为 $1$，求常数 $a, b$ 的值。
- **【考点定位】**
  - 含参最高次系数 $a$ 的符号分类讨论（$a > 0,\; a = 0,\; a < 0$）与待定系数法。
- **【分步标准解答】**
  $f(x) = ax^2 - 2ax + b = a(x - 1)^2 - a + b$ と変形できる。
  $a$ の符号によってグラフの凹凸が変わるため、$a > 0,\; a = 0,\; a < 0$ に場合分けして考える。
  > 💡 讲师批注：本题最容易漏掉 **$a < 0$**（开口向下）的情况！而且题干只说「関数」未说「二次関数」，因此规范解答必须明确检验 **$a = 0$** 并将其排除！

  また、$a \neq 0$ のとき軸は直線 $x = 1$ であり、定義域 $0 \leqq x \leqq 3$ の中に含まれる。
  軸 $x = 1$ からの距離は $|3 - 1| = 2 > |0 - 1| = 1$ なので、$x = 3$ の方が軸から遠い。
  あらかじめ各点での値を求めると、
  $$f(1) = -a + b, \qquad f(3) = 9a - 6a + b = 3a + b$$

  **(i) $a > 0$ のとき**（グラフは下に凸）：
  - $x = 1$ で最小値 $f(1) = -a + b = 1$
  - $x = 3$ で最大値 $f(3) = 3a + b = 9$
  連立して解くと、$(3a + b) - (-a + b) = 9 - 1 \implies 4a = 8 \implies a = 2$。
  これは $a > 0$ を満たす。このとき $b = 1 + a = 3$。

  **(ii) $a = 0$ のとき**：
  $f(x) = b$（定数関数）となり、最大値と最小値が一致するため、「最大値 $9$、最小値 $1$」という条件を満たさない（不適）。

  **(iii) $a < 0$ のとき**（グラフは上に凸）：
  - $x = 1$ で最大値 $f(1) = -a + b = 9$
  - $x = 3$ で最小値 $f(3) = 3a + b = 1$
  連立して解くと、$(3a + b) - (-a + b) = 1 - 9 \implies 4a = -8 \implies a = -2$。
  これは $a < 0$ を満たす。このとき $b = 9 + a = 7$。

  以上 (i)〜(iii) より、求める $a, b$ の値は $(a, b) = (2, 3),\; (-2, 7)$。
  > 💡 讲师批注：代入验算：$(2, 3) \implies f(x) = 2(x-1)^2 + 1$，最小 $1$、最大 $2\cdot2^2+1 = 9$；$(-2, 7) \implies f(x) = -2(x-1)^2 + 9$，最大 $9$、最小 $-2\cdot2^2+9 = 1$，均满足题意！
- **【最终答案】**
  **$(a, b) = (2, 3),\; (-2, 7)$**

#### 演習問題 3-(2)
- **【原题重现与翻译】**
  - 原题：$(2)\ \sqrt{2}x^2 - 5x + 2\sqrt{2} = 0$
  - 中文：解方程 $\sqrt{2}x^2 - 5x + 2\sqrt{2} = 0$。
- **【考点定位】**
  - 含无理数系数的二次方程（十字相乘法 / 两边乘 $\sqrt{2}$ 有理化）。
- **【分步标准解答】**
  **解法 1（たすき掛けによる因数分解）**：

  $$(\sqrt{2}x - 1)(x - 2\sqrt{2}) = 0$$
  $$x = \frac{1}{\sqrt{2}},\; 2\sqrt{2}$$

  $$x = \frac{\sqrt{2}}{2},\; 2\sqrt{2}$$

- **【最终答案】**
  **$x = \dfrac{\sqrt{2}}{2},\; 2\sqrt{2}$**

#### 演習問題 3-(3)
- **【原题重现与翻译】**
  - 原题：$(3)\ 3(x + 1)^2 + 5(x + 1) - 2 = 0$
  - 中文：解方程 $3(x + 1)^2 + 5(x + 1) - 2 = 0$。
- **【考点定位】**
  - 换元法（置き換え）+ 十字相乘法。
- **【分步标准解答】**
  $x + 1 = t$ とおくと、方程式は
  $$3t^2 + 5t - 2 = 0$$
  たすき掛けにより因数分解すると、
  $$(3t - 1)(t + 2) = 0$$
  $$t = \frac{1}{3},\; -2$$

  $$x + 1 = \frac{1}{3} \implies x = -\frac{2}{3}$$
  $$x + 1 = -2 \implies x = -3$$
  > 💡 讲师批注：不要傻傻地把 $(x+1)^2$ 展开！看到重复出现的整体 $(x+1)$ 就果断换元，既快又不易算错。
- **【最终答案】**
  **$x = -3,\; -\dfrac{2}{3}$**

#### 演習問題 3-(4)
- **【原题重现与翻译】**
  - 原题：$(4)\ x^2 + x + |x - 1| = 5$
  - 中文：解方程 $x^2 + x + |x - 1| = 5$。
- **【考点定位】**
  - 含绝对值的一元二次方程（去绝对值分类讨论 + 解的范围检验）。
- **【分步标准解答】**
  絶対値の中身 $x - 1$ の符号によって場合分けする。

  **(i) $x \geqq 1$ のとき**：$|x - 1| = x - 1$ であるから、
  $$x^2 + x + (x - 1) = 5$$
  $$x^2 + 2x - 6 = 0$$
  解の公式（$b' = 1$）より、
  $$x = -1 \pm \sqrt{1^2 - 1 \cdot (-6)} = -1 \pm \sqrt{7}$$
  ここで $2 < \sqrt{7} < 3$ より、$-1 + \sqrt{7} > 1$ は $x \geqq 1$ を満たすが、$-1 - \sqrt{7} < 0$ は満たさない。
  よって、$x = -1 + \sqrt{7}$。
  > 💡 讲师批注：求出的解**必须**代回前提条件 $x \geqq 1$ 检验（吟味）！$\sqrt{7} \approx 2.646$，故 $-1 + \sqrt{7} \approx 1.646 \geqq 1$ 符合。

  **(ii) $x < 1$ のとき**：$|x - 1| = -(x - 1) = -x + 1$ であるから、
  $$x^2 + x + (-x + 1) = 5$$
  $$x^2 - 4 = 0 \implies x = \pm 2$$
  $x < 1$ を満たすものは $x = -2$ のみである（$x = 2$ は不適）。

  (i), (ii) より、求める解は $x = -2,\; -1 + \sqrt{7}$。
- **【最终答案】**
  **$x = -2,\; -1 + \sqrt{7}$**

#### 演習問題 3-(6)
- **【原题重现与翻译】**
  - 原题：$(6)\ (\sqrt{3} - 1)x^2 + 2x + (\sqrt{3} + 1) = 0$
  - 中文：解方程 $(\sqrt{3} - 1)x^2 + 2x + (\sqrt{3} + 1) = 0$。
- **【考点定位】**
  - 含无理数系数的二次方程求根 + 虚数解与分母有理化（衔接教材 P56–P57 虚数解概念）。
- **【分步标准解答】**
  $x$ の係数が偶数 $2 = 2 \cdot 1$ であるから、解の公式（$b' = 1$）を用いる。
  $$x = \frac{-1 \pm \sqrt{1^2 - (\sqrt{3} - 1)(\sqrt{3} + 1)}}{\sqrt{3} - 1}$$
  ここで $(\sqrt{3} - 1)(\sqrt{3} + 1) = 3 - 1 = 2$ であるから、
  $$x = \frac{-1 \pm \sqrt{1 - 2}}{\sqrt{3} - 1} = \frac{-1 \pm \sqrt{-1}}{\sqrt{3} - 1} = \frac{-1 \pm i}{\sqrt{3} - 1}$$
  > 💡 讲师批注：绝妙的平方差巧合！$(\sqrt{3}-1)(\sqrt{3}+1) = 2$，使得根号内直接化简为 $1 - 2 = -1$，即虚数单位 $i$！

  分母を有理化するため、分母・分子に $\sqrt{3} + 1$ を掛けると、
  $$x = \frac{(-1 \pm i)(\sqrt{3} + 1)}{(\sqrt{3} - 1)(\sqrt{3} + 1)} = \frac{-(\sqrt{3} + 1) \pm (\sqrt{3} + 1)i}{2}$$
  > 💡 讲师批注：若仅在「数学Ⅰ（実数解の範囲）」内作答，则结论为「**実数解はない**」；由于本教材 P56–P57 刚刚引入了「虚数解（共役な複素数）」，因此本题标准答案为上述一对共轭复数解！备课时务必提醒学生区分考题问法（「解け」vs.「実数解を求めよ」）。
- **【最终答案】**
  **$x = \dfrac{-(\sqrt{3} + 1) \pm (\sqrt{3} + 1)i}{2}$**（実数の範囲では解なし）

#### 演習問題 3-(8)-[1]
- **【原题重现与翻译】**
  - 原题：次の二次方程式の解の種類を判別せよ。ただし、$k$ は定数とする。$[1]\ 2x^2 - (k + 2)x + k - 1 = 0$
  - 中文：判别下列二次方程解的种类（$k$ 为常数）：$2x^2 - (k + 2)x + k - 1 = 0$。
- **【考点定位】**
  - 判别式为关于 $k$ 的二次式，通过**配方**证明恒正（$D > 0$）。
- **【分步标准解答】**

  $$D = \{-(k + 2)\}^2 - 4 \cdot 2 \cdot (k - 1)$$

  $$= k^2 - 4k + 12$$

  $$D = (k - 2)^2 - 4 + 12 = (k - 2)^2 + 8$$
  > 💡 讲师批注：看到判别式 $D$ 展开后是关于 $k$ 的二次三项式且无法实数因式分解，立刻想到**配方**判断恒正或恒负！

  任意の実数 $k$ に対して $(k - 2)^2 \geqq 0$ であるから、
  $$D = (k - 2)^2 + 8 \geqq 8 > 0$$
  よって、$k$ の値にかかわらず、常に**異なる 2 つの実数解をもつ**。
- **【最终答案】**
  **$k$ の値にかかわらず、異なる 2 つの実数解をもつ**

#### 演習問題 3-(9)-[1]
- **【原题重现与翻译】**
  - 原题：次の条件を満たす定数 $a$ の値の範囲を求めよ。$[1]\ x^2 - 2ax + a^2 + a - 5 = 0$ が実数解をもつ。
  - 中文：求满足下列条件的常数 $a$ 的取值范围：$x^2 - 2ax + a^2 + a - 5 = 0$ 有实数解。
- **【考点定位】**
  - 「実数解をもつ（有实数解）」等价于 **$D \geqq 0$**（包含重解！）。
- **【分步标准解答】**
  二次方程式が実数解をもつための必要十分条件は、判別式 $D \geqq 0$（すなわち $\dfrac{D}{4} \geqq 0$）である。
  $$\frac{D}{4} = (-a)^2 - 1 \cdot (a^2 + a - 5) = a^2 - a^2 - a + 5 = -a + 5$$
  $\dfrac{D}{4} \geqq 0$ より、
  $$-a + 5 \geqq 0 \implies a \leqq 5$$
  > 💡 讲师批注：切记「実数解をもつ」=「有 2 个不同实解 **或** 1 个重解」，所以是 **$D \geqq 0$**（带等号），千万不要漏掉等号！
- **【最终答案】**
  **$a \leqq 5$**

#### 演習問題 3-(9)-[2]

- **【分步标准解答】**
  方程式 $ax^2 - (2a - 3)x + a = 0$ が異なる 2 つの実数解をもつためには、まず二次方程式でなければならない。すなわち、
  $$a \neq 0 \quad \cdots \text{①}$$
  > 💡 讲师批注：**EJU 顶级避坑点！** 如果 $a = 0$，原方程退化为一次方程 $3x = 0$，只有 $1$ 个解 $x = 0$，绝不可能有「2 个不同实数解」！做含参 $ax^2 + bx + c = 0$ 题时，第一行就必须检查 $a \neq 0$！

  かつ、判別式 $D > 0$ を満たす必要がある。
  $$D = \{-(2a - 3)\}^2 - 4 \cdot a \cdot a$$
  $$= (4a^2 - 12a + 9) - 4a^2$$
  $$= -12a + 9$$
  $D > 0$ より、
  $$-12a + 9 > 0 \implies 12a < 9 \implies a < \frac{3}{4} \quad \cdots \text{②}$$
  ①、② の共通範囲を求めると（上図）、
  $$a < 0 \quad \text{または} \quad 0 < a < \frac{3}{4}$$
  > 💡 讲师批注：亦常写作「$a < \dfrac{3}{4}$ ただし $a \neq 0$」，两种写法在 EJU 中均完全等价。
- **【最终答案】**
  **$a < 0$ または $0 < a < \dfrac{3}{4}$**（すなわち $a < \dfrac{3}{4}$ ただし $a \neq 0$）

## 三、表述不严谨 / 需注意（非错误）

以下内容原书**不算印错**，但照字面理解或套公式极易踩坑，笔记中已加批注提醒：

| 位置 | 原书内容 | 注意点 |
| :--- | :--- | :--- |
| P.13 vs P.17–28（PDF p.14 vs p.18–29） | 静/动摩擦系数符号前后不统一 | P.13 用 $(\mu, \mu')$，P.17–28 用 $(\mu_0, \mu)$，做题务必以题干给定符号为准 |
| P.48 / PDF p.49 | 热气球例题符号 $M$ 前后复用 | (1)–(3) 问的 $M$ 指空气**摩尔质量**，(4)–(5) 问重新定义为**气球自身质量**，切勿混淆 |
| P.65 / PDF p.66 | 音速公式 $V = 331.5 + 0.6t$ | 公式框内未注明 $t$ 为**摄氏温度 $[^\circ\text{C}]$**（不是绝对温度 $T$） |
| P.67 / PDF p.68 | 弦的固有振动数 $f_n = \dfrac{n}{2l}\sqrt{\dfrac{S}{\rho}}$ | 未注明字母含义：$S\text{ [N]}$ 为弦的张力，$\rho\text{ [kg/m]}$ 为**线密度**（非体积密度） |
| P.74 / PDF p.75 | 单缝衍射配图与次极大公式 | 配图标出 $B_0, B_{12}$ 未解释半波带配对法；次极大明线条件 $d\sin\theta = (m+\frac{1}{2})\lambda$ 仅为近似位置 |
| P.75 / PDF p.76 | 薄膜干涉公式 | 默认空气—薄膜—空气（1 次半波损失）；若为玻璃防反射镀膜（$n_{\text{空気}} < n_{\text{膜}} < n_{\text{ガラス}}$），发生 2 次半波损失，明暗条件互换 |
| P.77 / PDF p.78 | 库仑定律 $F = k\dfrac{q_1 q_2}{r^2}$ | 未加绝对值符号，求力的**大小**时应取 $F = k\dfrac{\|q_1 q_2\|}{r^2}$ |
| P.103 / PDF p.104 | 交流电动势峰值 $V_0 = \Phi_0 \omega$ | 仅针对单匝线圈（$N=1$），多匝线圈一般式为 $V_0 = NBS\omega$ |
| P.75–112 / PDF p.76–113 | 页眉统一印作「物理基礎」 | 薄膜干涉、透镜、电磁学后半、交流电及原子物理在日本官方大纲中均属**「物理（専門 / 発展）」**范畴 |

## 四、备考优先级：建议红笔必改清单

以下 **🔴 必改项** 与高频 **🟠 / 🟡 失分项** 建议直接在纸质教材上用红笔标出或补全：

1. **P.112（PDF p.113）**：大标题「ボール模型」→ 改为 **「ボーア模型」**
2. **P.63（PDF p.64）**：波的干涉条件旁补写前提 **「同位相の 2 つの波源」**（逆位相则强弱互换）
3. **P.95（PDF p.96）**：安培力公式 $F = IBl\sin\theta$ 旁补注 **$\theta$ 为电流与磁场夹角**
4. **P.98（PDF p.99）**：带电粒子螺旋运动配图旁注明斜入射半径应为 **$r = \dfrac{mv\sin\theta}{qB}$**

7. **P.99 / P.101–102 / P.110**：在书页空白处补抄 3 个 EJU 高频漏印公式——霍尔电压 **$V_H = \dfrac{IB}{ent}$**、螺线管电感 **$L = \mu n^2 Sl$ / $M = \mu n_1 n_2 Sl$**、X 射线最短波长 **$\lambda_0 = \dfrac{hc}{eV}$**

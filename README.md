# EJU Notes — Chemistry, Physics & Math

Bilingual Japanese–Chinese EJU lecture notes and complete textbook solutions with KaTeX math rendering, mhchem chemical equations, and inline SVG diagrams.

## Online Reading (GitHub Pages)

- **Portal**: https://hannirio.github.io/eju_notes/
- **Mathematics**: https://hannirio.github.io/eju_notes/eju_math_solutions.html
- **Physics**: https://hannirio.github.io/eju_notes/eju_physics_solutions.html
- **Chemistry**: https://hannirio.github.io/eju_notes/eju_chemistry_solutions.html

## Repository Structure

- `index.html` — Navigation portal for all three subjects
- `eju_math_solutions.html` — EJU Mathematics (Course 2) complete solutions
- `eju_physics_solutions.html` — EJU Physics complete solutions
- `eju_chemistry_solutions.html` — EJU Chemistry complete solutions
- `notes/` — Source Markdown notes by subject (`math/`, `physics/`, `chemistry/`), each with `glossary.md`, `errata.md`, and chapter `note_*.md`
- `scripts/` — Build, theme unification, SVG fix, and HTML QA scripts
